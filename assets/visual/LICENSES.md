# Visual Assets License Ledger

Everything the 3D world draws is generated by code at run time (R2627, docs/08 6.1 and 7.3). No image, texture, model or
shader file from another product ships, and none is fetched at run time. The table lists each source of pixels and its
license.

| What | Source | License | Verified Date |
|---|---|---|---|
| Block textures: albedo, normal, roughness and metalness (`procedural://textures/*`) | Generated deterministically in `apps/client/src/world/textures.ts` from value and cell noise (our code), then packed by `atlas.ts` | LCW first-party (CC0-1.0 compatible, nothing third-party) | 2026-11-19 |
| Voxel sky and block light, ambient occlusion | Computed in the mesh worker (`voxel-light.ts`, `mesher.ts`) | LCW first-party | 2026-11-19 |
| Sky, clouds, stars, water, wind | Shader code in `sky.ts` and `materials.ts` | LCW first-party | 2026-11-19 |
| Tone mapping and post effects (ACES filmic, bloom, grade) | three.js `ACESFilmicToneMapping`, `EffectComposer`, `UnrealBloomPass` (three 0.170, `three/examples/jsm`) and our grade shader in `post.ts` | three.js MIT | 2026-11-19 |
| Store signs, fascia, roof badges, minimap, store icons | Canvas drawing in `storefront.ts` and `wayfinding.ts` (colours from `@lcw/ui` tokens) | LCW first-party | 2026-11-19 |
| Sign lettering | Atkinson Hyperlegible (`@lcw/ui` `fonts.target`, docs/08 2.x) | SIL OFL 1.1 | 2026-11-19 |
| Characters and faces | Generated in `character.ts` | LCW first-party | 2026-11-19 |

How to check: `git ls-files | grep -iE '\.(png|jpe?g|webp|ktx2|basis|glb|gltf|hdr|exr)$'` lists no texture or model file
under `apps/client/src/world`.
