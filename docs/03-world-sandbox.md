# 03. 월드와 샌드박스

월드 규격과 놀이 도메인 13개입니다. 3장과 D1~D8의 수치는 v2에서 가져왔고, D9~D13은 이번 판에서 추가했습니다. 수치는 전부 출발값이며 `sim-core`의 튜닝 테이블 한 곳에 모읍니다.

## 3. 월드 규격

### 3.1 치수

| 항목 | 값 | 비고 |
|---|---|---|
| 블록 | 1m | |
| 청크 | 16 × 16 × 16m | 큐빅 청크 |
| 월드 평면 | 288 × 288m = 18 × 18 청크 | |
| 섹터 | 96 × 96m = 6 × 6 청크, 3 × 3 배치 | 걷기 4.5m/s 기준 섹터 한 변 약 21초, 월드 한 변 약 64초 |
| 수직 범위 | −400m ~ +1,000m | 최대 28,512 청크, 실제 저장은 변경분만 |
| 시야 | 수평 6청크, 수직 4청크 (기기 등급별 4~8) | |
| 하루 | 실시간 24분 | 50분 수업 = 게임 2일 |
| 멀티 월드 정원 | 플레이어 8명 | 싱글 월드는 룸 없이 클라이언트 단독 실행 |

### 3.2 수직 밴드

| 고도 | 밴드 | 환경 규칙 | 지형 방식 | 도달 수단 |
|---|---|---|---|---|
| +600 ~ +1,000 | 심우주·블랙홀 | 중력 0.05G, 산소 0, 중심 인력 | 메시 + 셰이더 (복셀 아님) | 우주선, 4티어 제트팩 |
| +300 ~ +600 | 우주 정거장 | 중력 0.2G, 산소 0 | 프리팹 메시, 내부만 블록 설치 가능 | 제트팩 + 우주복, 궤도 엘리베이터 |
| +80 ~ +300 | 하늘섬 | 강풍(수평 밀림), 낙하 주의 | 희소 복셀 섬 | 이단 점프 부츠, 블록 쌓기, 제트팩 |
| −8 ~ +80 | 지상 | 1.0G, 낮밤, 섹터별 기후 | 복셀 지형 + 복셀 프리팹 건물 | 걷기 |
| −150 ~ −9 | 광산 | 조도 0, 섹터별 광물표 | 복셀 (3D 노이즈 동굴) | 곡괭이, 폭약, 광산 엘리베이터 |
| −400 ~ −150 | 네더 | 고열(방열복 없으면 열 게이지 감소) | 복셀, 전 섹터 공통 | 드릴, 심층 엘리베이터 |

- 한 번 도달한 밴드는 광장 엘리베이터에 정류장이 열립니다. 재방문에 수 분씩 쓰지 않게 하기 위함입니다.
- 정거장과 블랙홀을 메시로 처리하는 이유: 그 고도에서는 "부수고 짓기"보다 "미션과 대화"가 핵심이라 복셀 비용을 쓸 이유가 없습니다.

### 3.3 월드 생성 알고리즘 (결정론)

입력은 `seed(64bit)`와 `gen_version`뿐입니다. 같은 입력은 어느 기기에서든 같은 월드를 만듭니다.

1. **난수 스트림 분리**: `layout`, `terrain`, `ore`, `loot`, `npc` 스트림을 시드에서 파생합니다. 한 영역을 고쳐도 다른 영역 결과가 바뀌지 않습니다.
2. **섹터 배치**: 바이옴 팩 풀에서 8개를 뽑되 아래 제약을 만족할 때까지 재추첨합니다.
   - 더운 기후 1개 이상, 추운 기후 1개 이상, 도시형 2개 이상
   - 필수 서비스 4종(카페, 부티크, 제작소, 오피스·환전소)을 수용할 섹터가 각각 1개 이상
   - 같은 팩 중복 금지, 인접 섹터의 기후가 최대한 대비되도록 가중치 부여
3. **지형**: 섹터별 노이즈 파라미터로 높이맵 생성, 경계 8m 구간은 보간으로 이어 붙입니다.
4. **도로**: 중앙 광장의 네 게이트에서 각 섹터 중심까지 경로 탐색으로 도로를 깔아 접근성을 보장합니다.
5. **건물**: 팩이 선언한 프리팹(복셀 스탬프 + 복셀 소품)을 예약 부지에 배치합니다.
6. **지하**: 열(column)이 속한 섹터의 광물표를 적용하고, 사막 아래 피라미드 광산이나 설원 아래 얼음 동굴 같은 세트 피스를 심습니다. −150m 아래는 전 섹터 공통 네더입니다.
7. **하늘**: 섹터 테마에 맞는 하늘섬, +500m 정거장, +1,000m 블랙홀을 배치합니다.

저장은 `(seed, gen_version, layout)` + **변경된 청크의 델타**만 합니다. 생성 규칙을 개선해 `gen_version`을 올려도 유저가 한 번이라도 손댄 청크는 다시 생성하지 않습니다.

### 3.4 바이옴 팩 매니페스트

섹터 하나는 아래 데이터 한 덩어리입니다. 새 국가·기후 추가는 이 파일과 에셋만 올리면 끝납니다.

```json
{
  "id": "biome.london_rain",
  "climate": { "type": "rain", "temp": "mild", "gauge_mods": { "thirst": 0.8 } },
  "requires_gear": ["umbrella|raincoat"],
  "penalty_without_gear": { "move_speed": 0.85 },
  "services": ["boutique", "cafe"],
  "service_skins": { "boutique": "prefab.savile_tailor", "cafe": "prefab.tea_room" },
  "side_job": "job.umbrella_delivery",
  "ore_table": { "coal": 0.5, "iron": 0.35, "gold": 0.1, "ruby": 0.05 },
  "underground_setpiece": "set.victorian_sewer",
  "sky_feature": "sky.airship_dock",
  "vocab_themes": ["weather", "clothing", "politeness"],
  "ambient": { "skybox": "sky.overcast", "bgm": "bgm.london" }
}
```

출시 풀은 12팩(사하라, 런던, 알프스, 뉴욕, 아마존, 하와이, 도쿄, 텍사스 + 4개)을 권장합니다. 12개 중 8개 선택과 배치 순서만으로도 조합 수가 충분히 커서 같은 월드를 다시 만날 일이 사실상 없습니다.

### 3.5 중앙 섹터와 부지

```text
중앙 섹터 (96 x 96m)
+--------------------------------------------------+
|  [북 게이트]                                      |
|   법원·경찰서      엘리베이터 타워     복권방      |
|                                                  |
| [서 게이트]      중앙 광장 (스폰)      [동 게이트] |
|                                                  |
|   수리소           게시판·우체통                  |
|  +--------------------------------------------+  |
|  |  내 부지 32 x 32m (확장 시 최대 64 x 64m)   |  |
|  +--------------------------------------------+  |
|  [남 게이트]                                      |
+--------------------------------------------------+
월드 외곽 N/E/S/W: 도킹 게이트 4곳 (친구·교사 부지 64 x 64m가 붙는 자리)
```

- 내 부지 안에서는 내가 놓은 블록이 영구 보존됩니다. 공용 구역의 파괴는 60초 뒤 자동 복구됩니다.
- 방문자는 소유자가 허락한 경우에만 내 부지를 수정할 수 있습니다. 폭발도 같은 권한을 따릅니다.
- 집 안 상자는 무제한 보관함입니다. 5칸 슬롯의 결핍감은 "들고 다니는 것"에만 적용합니다.


## 4. 도메인

각 도메인은 `목표 → 핵심 루프 → 규칙과 수치 → 회화 접점 → 자동화` 순서로 적습니다.

### D1. 생존·외형

- **목표**: 접속 3분 안에 "말해야 할 이유"를 만든다.
- **루프**: 게이지 하락 → 상점 방문 → 발화 → 슬롯 수령 → 좌클릭 사용 → 버프.

| 게이지 | 100 → 0 소요(실시간) | 20% 이하 | 0% | 회복 |
|---|---|---|---|---|
| 배고픔 | 20분 | 이동 −15% | 달리기 불가 | 음식 (빵 +35) |
| 목마름 | 14분 (사막 2배 빠름) | 이동 −30% | 달리기·점프 약화 | 음료 (스무디 +50) |
| 체온 (한랭 섹터에서만) | 방한복 없으면 90초 | 이동 −40% | 화면 서리, 떨림 | 방한복, 따뜻한 음료(5분 유예) |
| 열 (네더에서만) | 방열복 없으면 60초 | 체력 감소 시작 | 광장 병원으로 귀환 | 방열복 |
| 산소 (+300m 이상) | 우주복 없으면 30초 | 경고음 | 정거장 에어록으로 귀환 | 우주복, 산소통 |

- 사망은 없습니다. 최악의 결과는 "느려짐"과 "귀환"입니다. 어린 유저가 좌절로 이탈하지 않게 하기 위함입니다.
- 스폰 직후 게이지는 45%로 시작합니다. 첫 방문 섹터의 카페 앞에는 반드시 1분 심부름 NPC가 있습니다(보상 50코인).
  - 지금 구현(WP-111): 꿀벌 카페 문 앞의 이웃 미나(`errand_neighbor`, `ctx:'errand'`)가 심부름을 줍니다(안내인 루나는 길 안내만). "꿀벌 카페에서 시원한 물 한 잔" → 수락 문장 통과(`errand_accept`) → 카페에서 물을 주문(첫 주문, 장부에서 값 차감) → 미나에게 건네는 문장(`errand_deliver`) → 장부 +50(`errand:first`, 한 번만), 물은 가방에서 `given`으로 빠지고 손·슬롯에서도 빠집니다(`takeItem`). 상태는 서버 `errands` 표가 가지며(`offered → accepted → carrying → done`), 사지 않고 건네거나 다른 음료를 사면 넘어가지 않습니다. 수업 문장은 심부름을 움직이지 않습니다.
  - 활성화 시계: 첫 `GET /v1/errand`(첫 접속) 시각 `started_at`, 첫 통과 문장 `first_pass_at`, 첫 주문 `first_order_at`, 끝 `done_at`을 같은 줄에 남깁니다(docs/01 활성화, docs/09 첫 문장까지 시간).
- **외형**: 캐릭터 1종 + 소켓 6개(머리, 몸, 등, 발, 오른손, 탈것). 착용 장비는 슬롯을 차지하지 않습니다. `F5`는 3인칭, `Tab`은 거울 뷰이고 모바일은 화면 버튼으로 대응합니다.
- **회화 접점**: 카페(요청·수량), 부티크(묘사·선호·사이즈).
- **자동화**: 날씨와 기후 이벤트는 시드 + 게임 시간으로 결정되며 서버 호출이 없습니다.

### D2. 채굴·제작

- **목표**: 영어 없이도 재미있는 "손맛 구간"을 주고, 한계에 부딪히면 제작소로 보낸다.
- **루프**: 채굴 → 도구 한계 → 환전 → 제작소 주문 → 더 깊이.

| 광물 | 기준가(코인) | 필요 도구 | 주 분포 |
|---|---|---|---|
| 석탄 | 4 | 나무 곡괭이 | −9 ~ −60 |
| 철 | 10 | 나무 곡괭이 | −20 ~ −90 |
| 금 | 35 | 철 곡괭이 | −60 ~ −130, 사막 지하에 2배 |
| 루비 | 50 | 철 곡괭이 | 사막 지하 세트 피스 |
| 다이아몬드 | 90 | 드릴 | −100 ~ −150, 설원 지하에 2배 |
| 네더 크리스탈 | 220 | 레이저 | −150 이하 |
| 블랙홀 파편 | 600 | 4티어 채굴기 | +600 이상 |

| 장비 | 정가 | 3성가 | 비고 |
|---|---|---|---|
| 철 곡괭이 | 300 | 150 | |
| 다이너마이트 5개 (`dynamite_x5`) | 150 | 75 | 반경 3m 파괴 |
| 드릴 (`drill`) | 350 | 175 | 연속 채굴. 단품 |
| 드릴 묶음 (`drill_bundle`) | 500 | 250 | 드릴 1 + 다이너마이트 5개를 담은 **별도 상품**. 단품 두 개의 합과 가격이 같으므로 할인이 아니라 한 번에 사는 편의입니다 |
| 이단 점프 부츠 | 800 | 400 | 하늘섬 진입 |
| 제트팩 | 2,000 | 1,000 | 3성은 연료 2배 |
| 방한복 / 사막 망토 | 400 / 350 | 200 / 175 | |
| 정장 | 600 | 300 | 면접 조건 |
| 방열복 | 2,500 | 1,250 | 네더 |
| 우주복 | 3,500 | 1,750 | 정거장 |

- **아이템 사양(ItemSpec)**: 제작 결과는 `05`의 1.1이 정한 **조립형 v2 명세**(`kind: "item"`, `v: 2`, `parts`, `tags`, `power{limit, used}`)의 JSON입니다. 이 문서와 `04`의 4.5는 같은 스키마(`packages/schemas`의 `ItemSpecV2Schema`)를 쓰며, 예전의 `base_mesh`·`shader_params`·`physics_tags`·`power_budget` 형식은 폐기했습니다. LLM이 과도한 성능의 아이템을 찍어내지 못하도록 **파워 예산**을 둡니다. 태그마다 비용이 있고 아이템 티어마다 예산 상한이 있어, 검증기가 초과분을 자릅니다. 내구도와 복습 카드(`memory_card_id`)는 명세가 아니라 소지품 기록(인벤토리 행)이 가집니다. 명세는 모양과 태그만 갖습니다.

```json
{
  "kind": "item", "v": 2,
  "name": "Red Jetpack",
  "socket": "Back_Socket",
  "parts": [
    { "id": "barrel_tube", "pos": [-0.2, 0, 0], "color": "#C0392B" },
    { "id": "barrel_tube", "pos": [0.2, 0, 0], "color": "#C0392B" },
    { "id": "nozzle_flare", "pos": [0, -0.5, 0], "color": "#F5B041", "glow": 0.2 }
  ],
  "tags": ["flight_jetpack", "fuel_x2"],
  "tier": 2,
  "power": { "limit": 10, "used": 9 }
}
```

- **회화 접점**: 제작소(목적절 `so that`, `in order to`), 환전소(숫자·흥정).
- **자동화**: 광물 시세는 월드 단위 평균 회귀 모델입니다. 같은 광물을 많이 팔수록 그 월드에서만 가격이 내려가고 시간이 지나면 돌아옵니다. 다른 광물을 캐러 다른 섹터로 가게 만드는 장치입니다.

### D3. 경제

- **목표**: 시간당 수입과 지출이 맞물려, 3성 할인이 체감될 만큼 코인이 빠듯해야 한다.

| 수입원(faucet) | 양 | 지출처(sink) | 양 |
|---|---|---|---|
| 1분 심부름 | 50 | 음식·음료 | 20 ~ 80 |
| 채굴(초반 10분) | 300 ~ 500 | 장비·의상 | 150 ~ 3,500 |
| 일급(직급별) | 400 ~ 2,000 | 수리(비복습 내구도) | 정가의 10% |
| 복권 | 기대값 63 ~ 139 | 건축 블록 | 개당 2 ~ 20 |
| 사회봉사 완료 | 100 | 벌금 | 잔액의 40%, 상한 3,000 |
| 마스터 도안 달성 보너스 | 200 | 부지 장식·NPC 영입 | 500 ~ 5,000 |

- **가격식**: `최종가 = 기준가 × 섹터 계수 × 시세 지수 × (1 − 별 할인)`. 별 할인은 1성 0%, 2성 20%, 3성 50%입니다.
- **힌트 페이드 보너스**: 키워드만 보고 말하면 추가 5%, 힌트 없이 말하면 추가 10%를 코인으로 환급합니다.
- **장부**: 모든 변동은 `ledger`에 `(계정, 변동, 사유, 대화 ID)`로 추가만 됩니다. 버그로 인한 복제·증발은 사유별 집계로 즉시 드러납니다.
- **현금 판매 금지**: 코인은 현금으로 살 수 없습니다. 좌석 하나로 모든 기능을 쓰는 원칙과 사행성·확률 규제 회피를 동시에 지키는 선입니다.

### D4. 커리어·사회

- **목표**: "정해진 시간에 다시 접속할 이유"와 격식 있는 영어를 쓸 무대를 만든다.
- **루프**: 정장 구매 → 면접(3턴) → 09:00 출근 → 고객 응대 2건 → 일급 → 승진.

| 직급 | 일급 | 승진 조건 | 주 언어 기능 |
|---|---|---|---|
| 인턴 | 400 | 출근 3일 | 자기소개, 요청 응대 |
| 사원 | 700 | 고객 응대 3성 5회 | 사과, 대안 제시 |
| 매니저 | 1,200 | 지각 0회로 5일 | 지시, 조건문 |
| 디렉터 | 2,000 | 협상 미션 3회 | 협상, 완곡 표현 |

- 시간은 **소유자가 접속해 있을 때만** 흐릅니다. 며칠 접속하지 않았다고 해고되지 않습니다.
- 지각하면 상사에게 사유를 말해야 합니다(과거 시제·변명). 통과하면 감봉 없음, 실패하면 그날 일급 50%.
- 섹터마다 부업이 하나씩 있습니다(우산 배달, 야간 방범, 농장 일손, 정거장 연구 보조). 팩 매니페스트의 `side_job`으로 선언합니다.
- **자동화**: 고객 클레임 시나리오는 문장 뱅크의 `office.customer.*` 묶음에서 레벨에 맞게 추첨합니다.

### D5. 카오스·법정

- **목표**: 일탈을 허용하되, 그 대가를 "가장 어려운 말하기"로 치르게 한다.
- **톤**: 만화적 슬랩스틱입니다. 다치는 사람은 없고 그을린 얼굴로 날아갔다가 걸어 돌아옵니다. 대외 명칭은 "폭탄 테러"가 아니라 **"대소동(Chaos)"**으로 씁니다. 학교·학부모·스토어 심사를 통과하려면 표현 수위가 중요합니다.
- **루프**: 공용 구역 파괴 또는 NPC 대상 장난 → 사이렌 → 법정 소환 → 벌금 또는 변론.

| 변론 결과 | 판결 |
|---|---|
| 벌금 선택 | 잔액의 40% (최소 200, 최대 3,000) |
| 1성 통과 | 벌금 50% |
| 2성 통과 | 사회봉사 (광장 청소 미션 + 문장 2개) |
| 3성 통과 | 무죄, 방청석 박수 연출 |

- **재범 누진**: 게임 하루에 2회 이상이면 벌금 계수가 오르고, 3회째는 하루 동안 도시 구역에서 폭약 사용이 잠깁니다. 소동이 가장 효율적인 돈벌이가 되는 것을 막습니다.
- **회화 접점**: 사과, 과거 시제 설명, 의도 부정(`I didn't mean to`), 약속(`I promise I will`).

### D6. 복권·건축

- **복권**: 100코인, 게임 하루 3장 제한, 가정법 공약(`If I win, I will ...`)의 별 등급이 상위 당첨 확률을 올립니다. 확률표는 복권방 벽에 항상 게시합니다.

| 등수 | 기본 확률 | 2성 | 3성(황금) | 상품 |
|---|---|---|---|---|
| 1등 | 0.1% | 0.2% | 0.3% | 5,000코인 + 전설 코스메틱 |
| 2등 | 0.5% | 1.0% | 1.5% | 3,000코인 + 24시간 제트팩 |
| 3등 | 6% | 12% | 18% | 300코인 |
| 4등 | 25% | 25% | 25% | 100코인(본전) |
| 기대값 | 63 | 101 | 139 | 장당, 구매가 100 |

- 3성 복권은 기대값이 구매가보다 높습니다. 좋은 문장에 대한 보상으로 의도한 것이며, 하루 3장 제한이 상한을 잡습니다.
- 당첨 공약은 기록됩니다. 당첨 후 공약한 물건을 실제로 사거나 지으면 "약속 지킴" 배지를 줍니다. 가정법이 미래 계획 표현으로 이어지는 장치입니다.
- **건축**: 내 부지에 블록을 하나씩 쌓습니다. 방 조건을 맞추면 해당 주민이 입주합니다. 요리사가 입주하면 집에서 주문 대화가 가능해집니다. 상세는 D13.
- **부지 확장**: 32m → 48m → 64m. 확장권은 플레이 업적과 수업 보상으로 얻습니다.

### D7. 수직 차원

- **목표**: 지상을 다 본 유저에게 수개월짜리 장기 목표를 준다.
- 밴드마다 **입장 장비 + 전용 부업 + 전용 어휘군**이 한 세트입니다.

| 밴드 | 입장 장비 | 부업 | 어휘군(레벨) |
|---|---|---|---|
| 하늘섬 | 이단 점프 부츠 | 구름 카페 서빙 | 날씨·방향·높이 (L2~L3) |
| 정거장 | 제트팩 + 우주복 | 연구 보조, 위성 수리 | 과학·절차 설명 (L4~L5) |
| 네더 | 드릴 + 방열복 | 크리스탈 납품 | 위험·경고·조건 (L3~L4) |
| 블랙홀 | 4티어 장비 | 외계 교신 | 추상·가정·토론 (L5~L6) |


### D8. 기억(망각곡선)

- **목표**: 한 번 말한 문장을 장기기억으로 넘긴다. 복습은 "숙제"가 아니라 "고장 난 내 물건 고치기"로 보이게 한다.
- **카드 생성**: 2성 이상으로 통과한 문장은 그 결과물(아이템·직급·판결)에 묶인 `memory_card`가 됩니다.
- **간격**: 20분(같은 세션) → 1일 → 3일 → 7일 → 16일 → 35일 → 마스터. 실패하면 한 칸만 후퇴합니다.
- **발현 방식**: 복습일이 된 카드의 아이템에 "연료 코어 경고" 같은 징후가 뜹니다. 바로 망가지지 않고 효율 50%로 작동합니다. 수리소나 해당 상점에서 문장을 다시 말하면 복구됩니다.
- **세션당 최대 3건**만 발현합니다. 장기간 미접속 후 돌아왔을 때 전부 고장 나 있으면 이탈하므로, 밀린 카드를 3건씩 풉니다.
- **발현 우선순위**: `우선순위 = (최근 7일 안에 장착·소켓에 끼웠거나 사용했는가 ? 10 : 0) + 복습 예정일을 넘긴 일수`. 높은 순으로 3건을 고릅니다. 지금 쓰는 장비(드릴, 제트팩)가 초반에 산 철 곡괭이·나무 검보다 항상 먼저 뜹니다.
- **창고 장비**: 장착하지 않고 7일 넘게 쓰지 않아 창고에 넣어 둔 장비는 징후가 뜨지 않습니다(슬롯을 차지하지 않음). 수리소 NPC에게 가서 플레이어가 직접 고를 때만 복습합니다. 구현은 `sim-core`의 `selectReviewSigns`(징후)와 `selectRepairPickCards`(수리소 선택)입니다.
- **힌트 단계와 간격의 결합**

| 복습 회차 | 화면 힌트 | 통과 기준 |
|---|---|---|
| 20분 | 전체 문장 | 내용어 70% 일치 |
| 1일 | 전체 문장 (음성 없음) | 70% |
| 3일 | 키워드 3개 | 70% |
| 7일 | 단어 첫 글자 | 65% |
| 16일 | 상황 그림만 | 60%, 같은 의미의 다른 표현 인정 |
| 35일 | 없음 | 60% → **마스터 도안** (영구 무제한 등급) |

- **요금제와의 관계**: 복습 엔진은 모든 좌석에 포함됩니다. 학습 효과를 요금 단계로 나누지 않습니다.
- **자동화**: `09-ops`의 P4.

### D9. 전투 (PvE·PvP)

- **목표**: 말하지 않고 싸우기만 해도 재미있어야 한다. 그리고 말하면 더 세져야 한다.
- **기본 규칙**: 체력 하트 10개(20HP). 좌클릭 공격, 우클릭 방어·조준. 피는 없고 별과 연기로 연출합니다.

| 무기 | 피해 | 비고 |
|---|---|---|
| 맨손 | 1 | |
| 나무 검 / 철 검 / 다이아 검 | 3 / 5 / 7 | 제작소에서 주문 |
| 활·새총 | 4 | 원거리, 화살 소모 |
| 지팡이 | 2 | 음성 스킬 위력 +50% |

| 적 | 출현 | HP | 피해 | 드롭 |
|---|---|---|---|---|
| 슬라임 | 지상 밤 | 8 | 2 | 젤리(5코인) |
| 박쥐 떼 | 광산 | 6 | 1 | 날개 조각 |
| 모래 전갈 | 사막 지하 | 16 | 3 | 독침(제작 재료) |
| 얼음 골렘 | 설원 지하 | 40 | 4 | 얼음 핵 |
| 용암 정령 | 네더 | 60 | 5 | 불씨 결정 |
| 구름 해파리 | 하늘섬 | 20 | 3 | 구름 실 |

| 공허 파편 | 블랙홀 | 80 | 6 | 파편 조각 |

- **쓰러짐**: 광장 병원에서 깨어나고 30초간 어지럼(이동 −30%). 치료비는 소지 코인의 5%(상한 100). 소지품은 잃지 않습니다.
- **방어구**: 머리·몸·발 소켓의 장비가 각각 방어 0~3을 줍니다. 받는 피해에서 방어 합을 뺍니다(최소 1).
- **음성 스킬**: `V`를 누른 채 명령을 말하면 발동합니다. 문법은 `동사 + (형용사) + 대상 (+ 이유·목적)`이고 기기에서 목록 대조로 인식합니다. LLM을 쓰지 않습니다.

| 발화 수준 | 예 | 위력 | 재사용 대기 |
|---|---|---|---|
| 단어 | `Freeze!` | 1.0배 | 8초 |
| 구 | `Freeze the big slime!` | 1.5배 | 8초 |
| 문장 | `Freeze the big slime so that I can escape!` | 2.5배 + 부가 효과 | 8초 |

  스킬 동사 12종으로 시작합니다: freeze, burn, push, pull, heal, shield, jump, light, call, break, slow, hide.
- **PvP**: 월드 설정값 `off`(기본) · `arena_only` · `on`. 플레이어 간 피해는 50%로 보정하고, 쓰러져도 잃는 것이 없습니다. 이긴 쪽은 트로피 점수를 얻습니다.
- **아레나**: 3분 라운드, 팀전·깃발 뺏기·말로만 싸우기(음성 스킬만 허용) 세 가지 규칙.
- **회화 접점**: 무기 주문, 수리, 음성 스킬, 전리품 판매 흥정.

| 모드 | 게이지 | 블록 | 특징 |

| 계정에 남는 것 | 월드에 남는 것 |

#### D10.1 월드 고르기 화면 (설계, 2026-11-16)

지금 열린 월드는 영어 마을 하나지만, 들어가는 길은 처음부터 **월드 고르기** 구조로 둡니다. 월드를 하나 더 여는 일이 코드 수정이 아니라 목록에 한 줄 더하는 일이 되게 하려는 것입니다(목표 언어 추가, 창작·캠페인 모드, 두 번째 마을).

- **월드 목록(단일 출처)**: `packages/content`의 `WORLDS` 배열. 한 항목이 한 월드 종류입니다.

| 필드 | 뜻 | 영어 마을 |
|---|---|---|
| `kind` | 월드 종류 id(저장 키에 들어감) | `'en-town'` |
| `titleKo` / `titleTarget` | 카드 제목(한국어 / 목표 언어) | '영어 마을' / 'English Town' |
| `targetLang` | 목표 언어. NPC 이름 팩(`npcCast(lang)`), 언어 팩, 음성이 이것으로 정해짐 | `'en'` |
| `mode` | D10 표의 모드 | `'survival_city'` |
| `town` | 월드가 짓는 마을 빌더와 장면 묶음 id(`town.ts` SCENES) | `'honey-town'` |
| `cover` | 카드 그림: 토큰 색 3~4개로 그리는 복셀 썸네일(이미지 파일 없음) | `['leaf','sky','honey']` |
| `status` | `'open'` 또는 `'soon'`(회색 카드 "곧 열려요"). 가격·결제 낱말은 쓰지 않음(AGENTS 4.9) | `'open'` |

- **누가 고르나**
  - 수업(`?code=`): 고르지 않습니다. 교사가 연 수업의 `world_id`가 정합니다. 수업 길(입장 → 이웃 → 카페 → 이웃)은 지금과 같습니다.
  - 연결된 아이·게스트: 열린 월드가 하나면 **고르기 화면 없이 바로 들어갑니다**(지금과 같은 1탭 입장). 둘 이상이면 처음 한 번 고르기 화면이 뜨고, 그 뒤로는 마지막 월드(`localStorage['lcw.lastWorld']`)로 바로 들어갑니다.
  - 들어간 뒤에는 왼쪽 위 장면 칩 옆의 '월드' 칩으로 언제든 고르기 화면을 엽니다(열린 월드가 하나면 칩을 숨김).
- **주소**: `/game/?world=<kind>`(바로 그 월드), `/game/?worlds=1`(고르기 화면). 모르는 `kind`면 고르기 화면을 엽니다.
- **화면**: 카드 격자(폰 1열, 태블릿 2열). 카드마다 복셀 썸네일, 제목 두 줄(한국어·목표 언어), 그 월드의 내 기록 한 줄('내 집 블록 132개', 서버 값), 탭 크기 56px 이상, 키보드로 고를 수 있음. 카드를 누르면 지금의 로딩(스플래시 → 발밑 지형) 그대로 그 월드가 시작됩니다.
- **월드 쪽 계약**: `createWorld({ world: WorldDef })`. 월드는 `WorldDef.town`으로 마을과 장면을 짓고, `targetLang`으로 NPC 이름(`npcPersona(id, targetLang)`, 없으면 town.ts 기본값)을 정합니다. 지금 `createWorld`의 다른 옵션은 그대로 둡니다.
- **서버 쪽 계약**: `GET /v1/worlds`(기기 토큰)가 이 아이에게 열린 월드와 월드별 기록을 줍니다. 저장 키는 `homeWorldId(player)`에서 `homeWorldId(player, kind)`로 넓히고, 기존 키는 `'en-town'`의 키로 그대로 읽습니다(옮겨 쓰기 없음). `kind`는 클라이언트가 고르지만 서버가 열린 목록에 있는지 다시 확인합니다(AGENTS 4.7).
- **단계**: ① 목록과 바로 입장(화면 변화 없음) → ② '월드' 칩과 고르기 화면(열린 월드 하나라 칩 숨김, `?worlds=1`로만 열림) → ③ 두 번째 월드를 `open`으로 바꾸면 칩이 보이고 첫 입장에 고르기 화면. 각 단계는 수업 길을 바꾸지 않습니다.
- **소유**: 목록은 콘텐츠(`packages/content`), 고르기 화면·칩·`createWorld({world})`는 월드(`App.tsx` 껍데기 슬롯), `/v1/worlds`와 저장 키는 엣지.

### D11. 멀티플레이와 공개 서버

- **입장 방법**: 초대 코드(6자리), 친구 목록, 공개 서버 목록, 게스트 패스.
- **소통 수단**

| 수단 | 범위 | 규칙 |
|---|---|---|
| 말풍선 | 모든 멀티 월드 | 말하기 버튼 → 인식 → 목표 언어 판별 → 필터 → 16m 안의 플레이어에게 글과 합성 음성으로 표시 |
| 문장 휠 | 모든 멀티 월드 | 상황별 문장 8개를 골라 보냄. 마이크가 없을 때 |

  말풍선은 목표 언어 토큰이 70% 이상일 때만 다른 사람에게 보입니다. 모국어로 말하면 본인에게만 "목표 언어로 말해 보세요"와 사전 기반 힌트가 뜹니다. 멀티플레이 자체가 회화 연습이 되고, 낯선 사람과의 자유 음성 채팅에서 생기는 위험이 없습니다.
- **플레이어 간 거래**: 거래 창에서 양쪽이 제안·수락 문장을 말합니다. 별 등급에 따라 거래 수수료가 10%, 5%, 0%입니다.
- **공개 서버**

| 항목 | 규칙 |
|---|---|
| 등록 | 소유자가 성인이거나 보호자가 승인한 경우 |
| 목록 카드 | 이름, 언어, 모드, 태그, 현재 인원, 대상 구분(모두·성인) |
| 미성년자 입장 | 보호자의 `public_servers` 동의가 있고 대상이 "모두"인 서버만 |
| 방문자 기본 권한 | 상호작용(상점·전투·거래). 건축은 소유자가 지정한 구역만. 월드 설정 `visitorBuild`(기본 꺼짐)가 꺼져 있으면 허가받지 않은 방문자는 부지·자유·도시 어디서도 블록을 놓거나 부술 수 없고, 폭발·로켓·물도 같은 판정을 지난다. 소유자가 켠 월드에서도 방문자는 부지에는 손댈 수 없다 |
| 도시·상점 보호 | 누구도 도시 구역에 금고 블록을 놓을 수 없고, 상점 출입구 앞 2칸은 보호 코어라 입구를 막을 수 없다 |
| 소유자 도구 | 추방, 차단, 말풍선 정지, 구역 권한, 방문자 편집 일괄 되돌리기 |
| 신고 | 서로 다른 3명이 신고하면 해당 플레이어의 말풍선 자동 정지, 운영자 확인함으로 |
| 가동 | 접속자가 1명 이상일 때만 룸이 깨어 있음 |

### D13. 건축 — 블록을 하나씩

- **목표**: 건물은 플레이어의 손에서만 나온다. 한 칸씩 쌓은 시간이 곧 애착이고, 그 애착이 쇼룸과 자랑과 재방문을 만든다.
- **원칙**: 한 번의 입력은 블록 한 개입니다. 채우기, 복사·붙여넣기, 대칭, 자동 건축, AI 건축은 생존 모드에도 창작 모드에도 없습니다.

| 조작 | 규칙 |
|---|---|
| 놓기 | 조준한 면에 1개. 도달 거리 5m. 누르고 있으면 초당 4개까지 연속(여전히 한 칸씩) |
| 부수기 | 좌클릭 유지. 블록 강도와 도구 등급으로 시간이 정해짐(0.2~3초) |
| 되돌리기 | 내가 놓은 최근 20개까지 `Z`로 회수 |
| 발판 | 발판 블록은 손으로 즉시 부서지고 100% 회수됨. 높은 곳 작업용 |
| 미리보기 | 놓일 자리에 윤곽선 표시. 놓을 수 없는 자리는 빨간 윤곽선과 사유 |
| 회전 | 계단·문·가구는 `R`로 방향 전환 |

- **블록 팔레트(약 120종)**

| 계열 | 예 | 얻는 곳 | 폭발 저항 |
|---|---|---|---|
| 흙·모래 | 흙, 잔디, 모래, 자갈, 눈 | 채집 | 낮음 |
| 돌 | 돌, 벽돌, 화강암, 대리석, 석재 계단·반블록 | 채굴, 석공 주문 | 중간 |
| 나무 | 판자 6종, 통나무, 울타리, 문, 사다리 | 벌목, 목공 주문 | 낮음~중간 |
| 유리·빛 | 유리, 색유리, 횃불, 랜턴, 네온 | 제작소 주문 | 매우 낮음 |

| 섹터 특산 | 사막 사암, 설원 얼음 벽돌, 정글 대나무, 도쿄 네온 간판, 정거장 패널 | 해당 섹터에서만 | 다양 |

  염색 가능한 블록은 16색입니다. 색은 주문할 때 말합니다.
- **재료 주문이 곧 회화**: "I need fifty red bricks and ten glass panes for my roof."처럼 재료·수량·색·용도를 말합니다. 별 등급이 높을수록 싸고 덤이 붙습니다. 건축가 놀이 방식의 말하기는 여기서 나옵니다.

- **방 판정**(주민 입주 조건): 문패 블록을 방 안쪽 벽에 붙이면 그 자리에서 안쪽 빈 공간을 따라가며 셉니다.

| 조건 | 값 |
|---|---|
| 닫힌 공간 | 빈 칸을 따라갔을 때 400칸 안에서 끝나야 함(넘으면 "막히지 않았거나 너무 큼") |

| 쉴 곳 | 침대 또는 의자 1개 이상 |
| 평평한 가구 | 탁자·작업대류 1개 이상 |
