# 07. 성장 측정과 학부모 대시보드

학부모가 확인하려는 것은 하나입니다. **아이가 자기 생각을 목표 언어로 꺼내 말하는 힘이 커지고 있는가.** 화면의 문장을 읽은 횟수는 그 답이 아닙니다. 그래서 이 문서의 모든 지표는 대본 없는 발화(`free`)를 중심에 둡니다.

## 1. 원자료

발화 한 건마다 기록하는 값입니다(`02`의 `utterances` 표).

| 값 | 얻는 방법 |
|---|---|
| 모드(`free`·`guided`·`read`·`recall`) | 회화 엔진의 상태 |
| 대화 상대(NPC·교사·친구·혼잣말) | 세션과 빙의 상태 |
| 세션 종류(혼자·멀티·수업) | 룸 종류 |
| 첫 발화 전사문, 목표 문장, 최종 전사문 | 인식 결과 |
| 목표 언어 단어 수, 모국어 단어 수 | 언어 팩 어휘 대조 |
| 발화 길이(ms) | 기기의 음성 활동 감지 |
| 반응 시간(ms) | 질문 음성이 끝난 시각부터 말하기 시작까지 |
| 별, 힌트 단계, 시도 횟수, 점수 | 채점 결과 |
| 인식 신뢰도 | 인식기 |

수업에서는 분 단위로 학생 발화 시간, 교사 발화 시간, 주고받기 횟수, 현재 활동을 추가로 기록합니다(`lesson_minutes`).

## 2. 지표 정의

| 영역 | 지표 | 정의 | 좋은 방향 |
|---|---|---|---|
| 발화량 | 자유 발화 단어 수 | 주간 `free` 발화의 목표 언어 단어 합 | 증가 |
| 발화량 | 말한 시간 | 주간 발화 길이 합(분) | 증가 |
| 유창성 | 말 속도 | `free` 단어 수 ÷ `free` 발화 시간(분) | 증가 후 안정 |
| 유창성 | 반응 시간 | `free` 발화 반응 시간의 중앙값 | 감소 |
| 유창성 | 발화 길이 | `free` 발화 한 건당 평균 단어 수 | 증가 |
| 복잡성 | 접속 표현 사용률 | `free` 100단어당 접속 표현 수(`because`, `so`, `if`, `when`, `that`, `so that` 등, 언어 팩 목록) | 증가 |
| 복잡성 | 레벨 | L1~L6 | 상승 |
| 어휘 | 누적 사용 어휘 | `read`가 아닌 모드에서 서로 다른 날 2회 이상 쓴 표제어 수 | 증가 |
| 정확성 | 첫 시도 통과율 | 1회차에 통과한 비율 | 증가 |
| 정확성 | 교정 거리 | 첫 발화와 1성 교정문의 정규화 편집 거리 | 감소 |
| 자발성 | 목표 언어 비율 | 첫 발화 중 목표 언어 단어 비율 | 증가 |
| 자발성 | 힌트 없는 발화 비율 | 전체 통과 발화 중 `free`와 `recall`의 비율 | 증가 |
| 기억 | 회상 성공률 | 복습 통과 ÷ 복습 시도 | 65% 이상 |
| 기억 | 마스터 문장 누적 | 35일 회상까지 통과한 문장 수 | 증가 |

### 2.1 생각말하기 지수

여러 지표를 한 숫자로 묶은 값입니다. 자기 자신의 출발점을 100으로 둡니다. 다른 아이와 비교하는 점수가 아닙니다.

```text
기준선 = 첫 2주의 각 지표 중앙값
비율(x) = 현재 4주 이동 평균 ÷ 기준선        (0.5 ~ 2.0으로 제한)
역비율(x) = 기준선 ÷ 현재 4주 이동 평균       (작을수록 좋은 지표)

단어당 준비 시간 = 반응 시간(latency_ms) ÷ max(1, 발화 단어 수)   (발화마다 계산한 뒤 평균)

지수 = 100 × ( 0.30 × 비율(발화 길이)
             + 0.20 × 비율(말 속도)
             + 0.15 × 역비율(단어당 준비 시간)
             + 0.15 × 비율(접속 표현 사용률)
             + 0.10 × 비율(목표 언어 비율)
             + 0.10 × 비율(힌트 없는 발화 비율) )
```

- **반응 시간은 단어당으로 정규화합니다.** 아이가 L1("Water, please")에서 L3("I'm looking for ... so that ...")로 올라가면 문장을 조립하느라 말을 시작하기까지 걸리는 시간이 당연히 늘어납니다. 원시 `latency_ms`로 역비율을 내면 실력이 오른 주에 지수가 떨어지는 역설이 생깁니다. 그래서 `단어당 준비 시간`(기준선도 같은 값)으로 비교하고, 같은 단어당 시간이라면 길고 어려운 문장을 말해도 이 항목은 깎이지 않습니다. 길어진 문장은 `발화 길이` 항목이 올려 줍니다.
- **레벨별 기대 반응 시간표(L1~L6)를 쓰지 않은 이유**: 표의 값은 출시 전에 근거 없이 정해야 하고, 아이마다 다른 자기 기준선(위의 "자기 자신의 출발점이 100")과 어긋납니다. 단어당 시간은 별도 표 없이 기준선과 같은 방식으로 계산되고, 레벨이 섞인 주에도 흔들리지 않습니다. 하한은 `THINK_SPEAK_MIN_LATENCY_PER_WORD_MS`(50ms/단어)로 0 나눗셈과 폭주를 막습니다.
- 구현: `packages/metrics`의 `computeWeeklyMetrics`(구성 지표 여섯: `free_mean_words`·`free_wpm`·`free_latency_per_word_ms`·`connectors_per_100`·`target_lang_ratio`·`hint_free_ratio`), `computeTwoWeekBaseline`, `computeThinkAndSpeakIndex`(가중치 `THINK_SPEAK_WEIGHTS`).
- **구성 지표의 범위**: 발화 길이·말 속도·단어당 준비 시간·접속 표현은 `free` 발화만, 목표 언어 비율은 유효 발화 전체의 단어, 힌트 없는 발화 비율은 통과한 발화(별 1개 이상 또는 점수 0.6 이상) 중 `free`·`recall`의 비율입니다.
- **기준선 = 표본이 충분한 첫 2주**: 처음 두 주 가운데 `free` 발화가 30건 이상인 주 두 개의 중앙값입니다. 5분짜리 체험 주가 아이의 100이 되지 않게 합니다. 두 주가 모이기 전에는 지수를 내지 않고 "준비 중"(`think_status: 'baseline'`)으로 보여 줍니다. 리포트처럼 아이의 이력이 없는 곳은 `THINK_SPEAK_DEFAULT_BASELINE`(L2 전형값, 측정값 아님)을 씁니다.
- **"현재"의 범위**: 주간 점은 그 주의 발화, 4주 선은 최근 4주 발화를 모아 같은 식으로 계산합니다. 여섯 지표가 모두 합의 비율이라 많이 말한 주라고 지수가 움직이지 않습니다. 예전 구현의 어휘 다양도(서로 다른 단어 ÷ 전체 단어)는 말을 많이 할수록 낮아져, 양만 늘어난 아이의 지수가 90까지 떨어지고 4주 선이 늘 주간 점보다 10쯤 낮게 그려졌습니다(12주 합성 시험에서 발견, 이 식에는 없는 항목이라 뺐습니다).
- **바닥값**: 기준선과 지금 값이 둘 다 바닥 아래면 비율은 1입니다(첫 2주에 접속 표현을 한 번도 안 썼어도 0÷0이 되지 않음). 바닥: 발화 길이 1단어, 말 속도 10단어/분, 준비 시간 50ms/단어, 접속 표현 100단어당 1회, 두 비율 0.05(`THINK_SPEAK_FLOORS`).
- 주간 `free` 발화가 30건 미만이면 그 주는 "표본 부족"으로 표시하고 지수를 계산하지 않습니다.
- 인식 신뢰도 0.5 미만 발화는 제외합니다.
- 지수 옆에는 항상 "어떻게 계산하나요" 링크와 여섯 구성 지표의 개별 그래프를 둡니다. 합성 점수만 보여 주면 근거를 물었을 때 답할 수 없습니다. 대시보드에서는 지수 카드 아래 「어떻게 계산하나요 · 구성 지표 6개」를 펼치면 식을 말로 풀어 쓴 설명과 지표마다 작은 그래프(출발점 점선, 표 보기)가 나옵니다(`apps/web/src/DashboardPage.tsx` `ThinkParts`).

### 2.2 수업 지표

| 지표 | 정의 | 목표 |
|---|---|---|
| 대화 밀도 | 수업 시간 중 누군가 말하고 있던 시간의 비율 | 60% 이상 |
| 학생 발화 점유율 | 학생 발화 시간 ÷ (학생 + 교사) 발화 시간 | 40~60% |
| 주고받기 | 화자가 바뀐 횟수, 10분당 | 25회 이상 |
| 최장 연속 발화 | 학생이 끊기지 않고 말한 가장 긴 구간(초) | 증가 |
| 고정 과제 지표 | 2분 이야기의 단어 수, 발화 길이, 말 속도, 접속 표현 수 | 4주 전 대비 증가 |

### 2.3 교사 기여 지표

"선생님 덕분"을 주장이 아니라 추적 가능한 사실로 보여 주기 위한 지표입니다.

| 지표 | 정의 | 보여 주는 문장 예 |
|---|---|---|
| 수업 유래 표현 | 수업에서 처음 등장한 표현(표현 핀 또는 자동 감지) | "이번 달 수업에서 새 표현 34개가 나왔습니다" |
| 수업 내 사용률 | 그중 학생이 같은 수업에서 직접 말한 비율 | "그중 29개를 그 자리에서 직접 말했습니다" |
| 전이율 | 그중 14일 안에 혼자 플레이에서 다시 쓴 비율 | "21개를 혼자서도 다시 썼습니다" |
| 정착률 | 그중 35일 회상까지 통과한 비율 | "12개는 한 달 뒤에도 힌트 없이 말했습니다" |
| 수업 효과 | 수업 세션과 혼자 세션의 발화 길이·말 속도 비교 | "수업에서는 한 번에 평균 9.2단어, 혼자서는 6.1단어를 말합니다" |
| 수업 뒤 상승 | 수업 다음 이틀간 혼자 플레이 지표와 그 외 날의 비교 | "수업 다음 날 자유 발화가 평소의 1.4배입니다" |
| 코칭 순간 | 교사의 `C` 핀 수와 전·후 클립 | 클립으로 직접 확인 |

이 지표들은 "수업에서 일어난 일과 그 뒤의 변화"를 기술합니다. 인과를 증명하지는 않습니다. 리포트 문장도 "덕분에 올랐다"가 아니라 "수업에서 나온 표현을 혼자서도 썼다"처럼 관찰된 사실로 씁니다. 사실이 충분히 쌓이면 결론은 학부모가 내립니다.

## 3. 복리 성장을 보여 주는 방법

1. **누적 곡선 세 줄**: 누적 자유 발화 단어, 누적 사용 어휘, 누적 마스터 문장. 최근 8주 추세를 점선으로 12주 앞까지 연장하고 "추정"이라고 적습니다.
2. **성장 배수**: "8주 전의 나와 비교해 발화 길이 1.5배, 말 속도 1.3배".
3. **복리 고리 그림**: 어휘가 늘면 문장이 길어지고, 긴 문장은 높은 별과 좋은 장비가 되고, 좋은 장비는 더 넓은 세계와 더 많은 대화로 이어진다는 순환을 그림 한 장으로.
4. **전·후 음성**: 같은 형식의 고정 과제를 첫 수업, 4주, 8주, 12주 시점으로 나란히.
5. **말한 날 달력**: 하루 자유 발화량을 색 농도로. 연속 기록이 한눈에 보입니다.

누적 곡선은 정의상 내려가지 않습니다. 그래서 반드시 주간 변화율 지표(발화 길이, 말 속도, 반응 시간)와 같은 화면에 둡니다. 누적만 보여 주면 정체기에도 성장하는 것처럼 보이고, 그것은 학부모를 속이는 일입니다.

## 4. 대시보드 구성

### 4.1 홈

| 영역 | 내용 |
|---|---|
| 한 줄 요약 | "이번 주 지우는 대본 없이 412단어를 말했습니다. 4주 전의 1.6배입니다." |
| 카드 4장 | 생각말하기 지수, 자유 발화 단어, 말한 시간, 마스터 문장. 각 카드에 4주 변화 화살표 |
| 이번 주의 한 마디 | 가장 긴 자유 발화 클립 재생 |
| 다음 수업 | 날짜, 수업 창문 입장 버튼 (과외 학생) |
| 돌아올 문장 | 이번 주 복습 예정 3개 |

### 4.2 성장

| 그래프 | 형태 | 조작 |
|---|---|---|
| 생각말하기 지수 | 주간 점 + 4주 이동 평균선, 수업일 표시 | 구성 지표 펼치기 |
| 누적 곡선 | 선 3개 + 추정 점선 | 기간 선택 |
| 주간 발화량 | 모드별 누적 막대 | 수업·혼자 전환 |
| 유창성 | 작은 그래프 3개(말 속도, 발화 길이, 반응 시간) | |
| 접속 표현 | 표현별 사용 횟수 막대 | 표현을 누르면 클립 |
| 레벨 사다리 | L1~L6 계단, 승급일 표시 | |
| 말한 날 달력 | 12주 열지도 | 날짜를 누르면 그날 클립 |

### 4.3 수업 (과외 학생)

| 영역 | 내용 |
|---|---|
| 수업 목록 | 날짜, 대화 밀도, 점유율, 대표 클립 |
| 수업 상세 | 120분 밀도 띠(구간 표시), 숫자, 고정 과제 전·후, 표현, 코칭 순간, 교사의 한마디 |
| 표현의 여정 | 수업 등장 → 수업 내 사용 → 혼자 재사용 → 마스터의 깔때기 |
| 수업과 혼자 비교 | 발화 길이, 말 속도, 자유 발화 비율의 막대 비교 |
| 수업 창문 | 수업 중일 때 입장 |

### 4.4 음성 박물관

아이 월드의 쇼룸 위에 아이템이 놓여 있고, 아이템을 누르면 그 물건을 얻을 때의 `첫 발화 → 선택한 문장 → 복습 때 발화`가 차례로 재생됩니다. 마스터 도안은 금색 테두리입니다.

### 4.5 설정

동의 관리(음성 저장, 수업 창문, 쇼룸 공개, 공개 서버), 친구 승인, 레벨 고정, 플레이 시간 안내, 데이터 내려받기와 삭제.

## 5. 문장 규칙

대시보드와 리포트의 모든 숫자에는 해석 한 줄을 붙입니다.

| 상황 | 문장 |
|---|---|
| 상승 | "한 번에 말하는 길이가 4주 전 5.8단어에서 7.4단어로 늘었습니다." |

| 하락 | "이번 주는 플레이가 2일뿐이어서 발화량이 줄었습니다." |
| 표본 부족 | "이번 주는 자유 발화가 적어 지수를 계산하지 않았습니다." |

금지: 근거 없는 칭찬, 다른 아이와의 비교, 시험 점수 환산, "덕분에"·"때문에" 같은 인과 표현.

## 7. 12주 합성 시뮬레이션 시험

12주 곡선이 아이가 실제로 한 일을 그대로 그리는지는 합성 아이로 시험합니다. 생성기 `packages/metrics/src/synthetic.ts`가 아이마다 성장 방식(플레이 요일, 하루 자유 발화 수, 문장 길이, 단어당 준비 시간, 말 속도, 접속 표현, 어휘 폭, 수업, 인식 잡음)을 받아 발화를 만들고, `simTruth`가 만든 것을 단순 합산해 정답을 냅니다. 시험은 대시보드 계산 코드가 아니라 이 합산과 비교합니다.

| 층 | 시험 | 무엇을 확인하나 |
|---|---|---|
| 계산 | `packages/metrics/src/__tests__/growth-12w.test.ts` | 아이 7명(꾸준히 크는 아이와 7주차 승급, 양만 늘어난 아이, 4주 뒤 정체, 2주 휴가와 이틀만 한 주, 5문장 체험 뒤 늦게 시작한 아이, 인식 잡음, 자정 넘겨 말하는 아이). 주간 양·누적 세 줄·달력 84일·수업한 주·추정 12주가 정답과 같은지, 누적이 내려가지 않는지, 지수 모양(승급 주에 꺼지지 않음, 양만 늘면 100 근처, 정체면 평평, 기준선이 체험 주를 건너뜀, 잡음이 아무 숫자도 바꾸지 않음) |
| 실제 경로 | `apps/edge/src/__tests__/growth-12w-e2e.test.ts` | 가짜 시계로 84일: 보호자 가입·좌석 결제·기기 연결 → 아이가 `/v1/converse/score`(자유·주문·낭독·잡음), `/v1/review/due`·`/attempt`(복습), 매주 수업(`/v1/admin/lessons/start` → `/v1/join` → `/v1/lesson/utterance` → 종료) → 매일 03시·매시·월요일 크론, 1일 전 안내가 뜨면 좌석 연장 → 보호자 `GET /v1/family/children/:pid/dashboard`. 서버의 곡선이 보낸 발화만으로 계산한 곡선과 같고(저장 = 보낸 것), 그 숫자가 단순 합산과 같은지. 요청 약 1,000건, 거절 0, 푸시 안내는 보류된 채 발송 0 |
| 화면 | `apps/web/src/__tests__/growth-12w-view.test.ts` | 합성 아이의 대시보드를 그려 한 줄 요약·카드 문장(늘었음·비슷함·이틀뿐)·지수 표·구성 지표 6개·추정 12행·"준비 중" 문구가 맞는지 |

- 로컬 화면 확인: `LCW_SIM_DUMP=<파일>`로 실제 경로 시험을 돌리면 저장된 행이 파일로 나옵니다. 이것을 로컬 wrangler의 DO에 넣고 `/dashboard`를 세 너비로 찍어 표 보기 숫자를 정답과 맞춥니다.
- 시뮬레이션이 찾은 것(다른 영역): 복습 징후는 최근 7일 안에 장착·사용한 장비만 뜨는데(`docs/09` P4), 서버에는 장착 상태도 수리소 선택 경로도 없고 "사용"은 직전 복습뿐입니다. 7일 간격 상자(3)에 오른 카드는 장비가 7일 창을 벗어나는 바로 그때가 복습일이라, 16일·35일 복습에 닿지 못하고 "마스터 문장" 곡선이 모든 아이에게 0에 머뭅니다. 실제 경로 시험의 `it.fails`가 이것을 붙잡고 있어, 고쳐지면 그 시험이 실패로 바뀌어 알려 줍니다.
- 누적 사용 어휘는 지금 표면형(소문자 단어) 기준입니다. 표제어로 묶으려면 언어 팩에 표제어 사전이 필요합니다.
