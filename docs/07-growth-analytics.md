# 07. 성장 측정과 학부모 대시보드

학부모가 확인하려는 것은 하나입니다. **아이가 자기 생각을 목표 언어로 꺼내 말하는 힘이 커지고 있는가.** 화면의 문장을 읽은 횟수는 그 답이 아닙니다. 그래서 이 문서의 모든 지표는 대본 없는 발화(`free`)를 중심에 둡니다.

## 1. 원자료

발화 한 건마다 기록하는 값입니다(`02`의 `utterances` 표).

| 값 | 얻는 방법 |
|---|---|
| 모드(`free`·`guided`·`read`·`recall`) | 회화 엔진의 상태 |
| 대화 상대(NPC·교사·친구·혼잣말) | 세션과 빙의 상태 |
| 세션 종류(혼자·멀티·수업) | 룸 종류 |
| 첫 발화 전사문, 목표 문장, 최종 전사문 | 인식 결과 |
| 목표 언어 단어 수, 모국어 단어 수 | 언어 팩 어휘 대조 |
| 발화 길이(ms) | 기기의 음성 활동 감지 |
| 반응 시간(ms) | 질문 음성이 끝난 시각부터 말하기 시작까지 |
| 별, 힌트 단계, 시도 횟수, 점수 | 채점 결과 |
| 인식 신뢰도 | 인식기 |

수업에서는 분 단위로 학생 발화 시간, 교사 발화 시간, 주고받기 횟수, 현재 활동을 추가로 기록합니다(`lesson_minutes`).

## 2. 지표 정의

| 영역 | 지표 | 정의 | 좋은 방향 |
|---|---|---|---|
| 발화량 | 자유 발화 단어 수 | 주간 `free` 발화의 목표 언어 단어 합 | 증가 |
| 발화량 | 말한 시간 | 주간 발화 길이 합(분) | 증가 |
| 유창성 | 말 속도 | `free` 단어 수 ÷ `free` 발화 시간(분) | 증가 후 안정 |
| 유창성 | 반응 시간 | `free` 발화 반응 시간의 중앙값 | 감소 |
| 유창성 | 발화 길이 | `free` 발화 한 건당 평균 단어 수 | 증가 |
| 복잡성 | 접속 표현 사용률 | `free` 100단어당 접속 표현 수(`because`, `so`, `if`, `when`, `that`, `so that` 등, 언어 팩 목록) | 증가 |
| 복잡성 | 레벨 | L1~L6 | 상승 |
| 어휘 | 누적 사용 어휘 | `read`가 아닌 모드에서 서로 다른 날 2회 이상 쓴 표제어 수 | 증가 |
| 정확성 | 첫 시도 통과율 | 1회차에 통과한 비율 | 증가 |
| 정확성 | 교정 거리 | 첫 발화와 1성 교정문의 정규화 편집 거리 | 감소 |
| 자발성 | 목표 언어 비율 | 첫 발화 중 목표 언어 단어 비율 | 증가 |
| 자발성 | 힌트 없는 발화 비율 | 전체 통과 발화 중 `free`와 `recall`의 비율 | 증가 |
| 기억 | 회상 성공률 | 복습 통과 ÷ 복습 시도 | 65% 이상 |
| 기억 | 마스터 문장 누적 | 35일 회상까지 통과한 문장 수 | 증가 |

### 2.1 생각말하기 지수

여러 지표를 한 숫자로 묶은 값입니다. 자기 자신의 출발점을 100으로 둡니다. 다른 아이와 비교하는 점수가 아닙니다.

```text
기준선 = 첫 2주의 각 지표 중앙값
비율(x) = 현재 4주 이동 평균 ÷ 기준선        (0.5 ~ 2.0으로 제한)
역비율(x) = 기준선 ÷ 현재 4주 이동 평균       (작을수록 좋은 지표)

지수 = 100 × ( 0.30 × 비율(발화 길이)
             + 0.20 × 비율(말 속도)
             + 0.15 × 역비율(반응 시간)
             + 0.15 × 비율(접속 표현 사용률)
             + 0.10 × 비율(목표 언어 비율)
             + 0.10 × 비율(힌트 없는 발화 비율) )
```

- 주간 `free` 발화가 30건 미만이면 그 주는 "표본 부족"으로 표시하고 지수를 계산하지 않습니다.
- 인식 신뢰도 0.5 미만 발화는 제외합니다.
- 지수 옆에는 항상 "어떻게 계산하나요" 링크와 여섯 구성 지표의 개별 그래프를 둡니다. 합성 점수만 보여 주면 근거를 물었을 때 답할 수 없습니다.

### 2.2 수업 지표

| 지표 | 정의 | 목표 |
|---|---|---|
| 대화 밀도 | 수업 시간 중 누군가 말하고 있던 시간의 비율 | 60% 이상 |
| 학생 발화 점유율 | 학생 발화 시간 ÷ (학생 + 교사) 발화 시간 | 40~60% |
| 주고받기 | 화자가 바뀐 횟수, 10분당 | 25회 이상 |
| 최장 연속 발화 | 학생이 끊기지 않고 말한 가장 긴 구간(초) | 증가 |
| 고정 과제 지표 | 2분 이야기의 단어 수, 발화 길이, 말 속도, 접속 표현 수 | 4주 전 대비 증가 |

### 2.3 교사 기여 지표

"선생님 덕분"을 주장이 아니라 추적 가능한 사실로 보여 주기 위한 지표입니다.

| 지표 | 정의 | 보여 주는 문장 예 |
|---|---|---|
| 수업 유래 표현 | 수업에서 처음 등장한 표현(표현 핀 또는 자동 감지) | "이번 달 수업에서 새 표현 34개가 나왔습니다" |
| 수업 내 사용률 | 그중 학생이 같은 수업에서 직접 말한 비율 | "그중 29개를 그 자리에서 직접 말했습니다" |
| 전이율 | 그중 14일 안에 혼자 플레이에서 다시 쓴 비율 | "21개를 혼자서도 다시 썼습니다" |
| 정착률 | 그중 35일 회상까지 통과한 비율 | "12개는 한 달 뒤에도 힌트 없이 말했습니다" |
| 수업 효과 | 수업 세션과 혼자 세션의 발화 길이·말 속도 비교 | "수업에서는 한 번에 평균 9.2단어, 혼자서는 6.1단어를 말합니다" |
| 수업 뒤 상승 | 수업 다음 이틀간 혼자 플레이 지표와 그 외 날의 비교 | "수업 다음 날 자유 발화가 평소의 1.4배입니다" |
| 코칭 순간 | 교사의 `C` 핀 수와 전·후 클립 | 클립으로 직접 확인 |

이 지표들은 "수업에서 일어난 일과 그 뒤의 변화"를 기술합니다. 인과를 증명하지는 않습니다. 리포트 문장도 "덕분에 올랐다"가 아니라 "수업에서 나온 표현을 혼자서도 썼다"처럼 관찰된 사실로 씁니다. 사실이 충분히 쌓이면 결론은 학부모가 내립니다.

## 3. 복리 성장을 보여 주는 방법

1. **누적 곡선 세 줄**: 누적 자유 발화 단어, 누적 사용 어휘, 누적 마스터 문장. 최근 8주 추세를 점선으로 12주 앞까지 연장하고 "추정"이라고 적습니다.
2. **성장 배수**: "8주 전의 나와 비교해 발화 길이 1.5배, 말 속도 1.3배".
3. **복리 고리 그림**: 어휘가 늘면 문장이 길어지고, 긴 문장은 높은 별과 좋은 장비가 되고, 좋은 장비는 더 넓은 세계와 더 많은 대화로 이어진다는 순환을 그림 한 장으로.
4. **전·후 음성**: 같은 형식의 고정 과제를 첫 수업, 4주, 8주, 12주 시점으로 나란히.
5. **말한 날 달력**: 하루 자유 발화량을 색 농도로. 연속 기록이 한눈에 보입니다.

누적 곡선은 정의상 내려가지 않습니다. 그래서 반드시 주간 변화율 지표(발화 길이, 말 속도, 반응 시간)와 같은 화면에 둡니다. 누적만 보여 주면 정체기에도 성장하는 것처럼 보이고, 그것은 학부모를 속이는 일입니다.

## 4. 대시보드 구성

### 4.1 홈

| 영역 | 내용 |
|---|---|
| 한 줄 요약 | "이번 주 지우는 대본 없이 412단어를 말했습니다. 4주 전의 1.6배입니다." |
| 카드 4장 | 생각말하기 지수, 자유 발화 단어, 말한 시간, 마스터 문장. 각 카드에 4주 변화 화살표 |
| 이번 주의 한 마디 | 가장 긴 자유 발화 클립 재생 |
| 다음 수업 | 날짜, 수업 창문 입장 버튼 (과외 학생) |
| 돌아올 문장 | 이번 주 복습 예정 3개 |

### 4.2 성장

| 그래프 | 형태 | 조작 |
|---|---|---|
| 생각말하기 지수 | 주간 점 + 4주 이동 평균선, 수업일 표시 | 구성 지표 펼치기 |
| 누적 곡선 | 선 3개 + 추정 점선 | 기간 선택 |
| 주간 발화량 | 모드별 누적 막대 | 수업·혼자 전환 |
| 유창성 | 작은 그래프 3개(말 속도, 발화 길이, 반응 시간) | |
| 접속 표현 | 표현별 사용 횟수 막대 | 표현을 누르면 클립 |
| 레벨 사다리 | L1~L6 계단, 승급일 표시 | |
| 말한 날 달력 | 12주 열지도 | 날짜를 누르면 그날 클립 |

### 4.3 수업 (과외 학생)

| 영역 | 내용 |
|---|---|
| 수업 목록 | 날짜, 대화 밀도, 점유율, 대표 클립 |
| 수업 상세 | 120분 밀도 띠(구간 표시), 숫자, 고정 과제 전·후, 표현, 코칭 순간, 교사의 한마디 |
| 표현의 여정 | 수업 등장 → 수업 내 사용 → 혼자 재사용 → 마스터의 깔때기 |
| 수업과 혼자 비교 | 발화 길이, 말 속도, 자유 발화 비율의 막대 비교 |
| 수업 창문 | 수업 중일 때 입장 |

### 4.4 음성 박물관

아이 월드의 쇼룸 위에 아이템이 놓여 있고, 아이템을 누르면 그 물건을 얻을 때의 `첫 발화 → 선택한 문장 → 복습 때 발화`가 차례로 재생됩니다. 마스터 도안은 금색 테두리입니다.

### 4.5 설정

동의 관리(음성 저장, 수업 창문, 쇼룸 공개, 공개 서버), 친구 승인, 레벨 고정, 플레이 시간 안내, 데이터 내려받기와 삭제.

## 5. 문장 규칙

대시보드와 리포트의 모든 숫자에는 해석 한 줄을 붙입니다.

| 상황 | 문장 |
|---|---|
| 상승 | "한 번에 말하는 길이가 4주 전 5.8단어에서 7.4단어로 늘었습니다." |
| 정체 | "이번 주 발화 길이는 지난 4주와 비슷합니다. L3로 올라간 직후에는 흔한 구간입니다." |
| 하락 | "이번 주는 플레이가 2일뿐이어서 발화량이 줄었습니다." |
| 표본 부족 | "이번 주는 자유 발화가 적어 지수를 계산하지 않았습니다." |

금지: 근거 없는 칭찬, 다른 아이와의 비교, 시험 점수 환산, "덕분에"·"때문에" 같은 인과 표현.

## 6. 계산 위치와 주기

| 시점 | 처리 | 위치 |
|---|---|---|
| 발화 채점 시 | 발화 단위 값 저장, 표제어 추출, 수업 유래 표현 재사용 여부 갱신 | Edge API |
| 수업 중 매분 | 발화 시간과 주고받기 집계 | 기기 → `LessonDO` |
| 수업 종료 시 | 수업 지표, 고정 과제 지표, 리포트 사실표 | `LessonDO` → D1 |
| 매일 새벽 | 주간 집계 갱신, 누적 곡선, 지수 | 크론 |
| 매주 월요일 | 주간 요약 생성과 푸시 | 크론 |
| 매월 1일 | 월간 성장 리포트(과외 학생은 교사 확인 후 발송) | 크론 |

지표 계산 코드는 `packages/metrics` 한 곳에 두고 단위 테스트로 고정합니다. 화면마다 따로 계산하면 숫자가 서로 어긋납니다.
