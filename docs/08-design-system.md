# 08. 디자인 시스템

화면, 그래픽, 조작, 움직임의 규칙입니다. 소리는 `12`, 소개 사이트는 `14`에 있습니다. 토큰은 `packages/ui/tokens.ts` 한 곳에 두고 게임 HUD, 대시보드, 소개 사이트가 함께 씁니다.

## 1. 방향

| 항목 | 결정 |
|---|---|
| 한 줄 | 따뜻한 장난감 블록의 세계. 만지고 싶고, 부숴도 다시 서고, 말을 걸면 대답한다 |
| 느낌 | 밝다, 둥글지 않고 네모나다, 과하게 귀엽지 않다(12세가 유치하다고 느끼지 않는 선) |
| 3D | 전부 복셀. 지형·건물·캐릭터·아이템·가구가 같은 격자 감각을 공유 |
| 2D UI | 크림색 종이 위 굵은 테두리와 딱딱한 그림자. 블러와 유리 효과는 쓰지 않음 |
| 금지 | 사실적 폭력 표현, 붉은 피, 도박장 연출, 결제 압박 연출, 참조 게임의 고유 외형 모방 |

대상이 둘입니다. 플레이어(주로 아동·청소년)가 보는 게임 화면은 색이 풍부하고 반응이 큽니다. 보호자가 보는 대시보드와 리포트는 같은 토큰을 쓰되 차분하고 숫자가 먼저 보입니다.

## 3. 글자

| 용도 | 서체 | 비고 |
|---|---|---|
| 한국어 UI·본문 | Pretendard | SIL OFL. 숫자는 고정폭 옵션 사용 |
| 목표 언어 문장(게임 내 영어) | Atkinson Hyperlegible | SIL OFL. I, l, 1과 O, 0이 뚜렷이 구분되어 학습용에 적합 |
| 제목·아이템 이름·HUD 숫자 | Galmuri11 | SIL OFL. 픽셀 서체. 12px의 배수로만 사용 |
| 읽기 쉬운 글자 옵션 | OpenDyslexic | 설정에서 선택 |

서체 라이선스는 착수 시 배포처에서 다시 확인합니다.

| 단계 | 크기 / 줄 높이 | 쓰임 |
|---|---|---|
| `display` | 48 / 56 | 소개 사이트 첫 화면 |
| `h1` | 36 / 44 | 페이지 제목 |
| `h2` | 28 / 36 | 구획 제목 |
| `h3` | 22 / 30 | 카드 제목, **대화창의 목표 문장** |
| `body-l` | 18 / 28 | 리포트 본문 |
| `body` | 16 / 24 | 기본 |
| `small` | 14 / 20 | 설명, 축 눈금 |
| `micro` | 12 / 16 | 꼬리표. 이보다 작은 글자는 쓰지 않음 |

목표 문장은 22px 아래로 내려가지 않습니다. 소리 내어 읽어야 하는 글자이기 때문입니다. 한 줄은 영어 45자 안팎에서 끊습니다.

## 5. 움직임

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `fast` | 120ms, ease-out | 버튼, 슬롯 선택 |
| `base` | 200ms, ease-out | 패널 열기 |
| `slow` | 320ms, ease-in-out | 대화 카메라 전환(내 눈에서 NPC 얼굴로 시선이 옮겨 감) |
| `pop` | 240ms, 1.0 → 1.15 → 1.0 | 별 획득, 아이템 수령 |

- 화면 흔들림은 최대 0.3도, 300ms. 연속 폭발에서도 누적하지 않습니다.
- 섬광은 초당 3회 이하, 화면의 25% 이하 면적으로 제한합니다. 광과민성 발작 위험을 낮추기 위한 기준입니다.
- "움직임 줄이기" 설정이 켜져 있으면 흔들림·섬광·시차 효과를 끄고 전환을 페이드로 바꿉니다.

## 6. 3D 아트

### 6.1 격자와 밀도 — LCW 장난감 블록

LCW의 블록은 "칠한 나무 장난감 블록"입니다. 다른 복셀 게임의 거친 픽셀 면(16텍셀 최근접 필터, 면 전체를 채운 판자 줄·책장 줄무늬)과 구분되도록 모양 언어를 따로 정했습니다(`15` 3장, AGENTS.md 4장 11).

| 대상 | 규격 |
|---|---|
| 지형·건축 블록 | 1m 정육면체, 면당 32 × 32 텍셀. 텍스처 배열(타일 1장 = 층 1개), 선형 필터 + 밉맵 |
| 블록 가장자리 | 셰이더 베벨: 위·왼쪽 가장자리는 밝게, 아래·오른쪽은 어둡게, 가운데는 살짝 부풀게. 세기는 타일마다(일반 1, 땅·길 0.35, 유리·잎·꽃·횃불·사다리 0) |
| 반블록·계단·울타리 | 같은 텍셀 밀도의 부분 형태 |
| 아이템·가구·소품 | 둥근 모서리 상자 조각을 합친 한 덩어리(소품 하나 = 그리기 1번) |
| 캐릭터 | 6.2의 둥근 장난감 인형. 그리기 1번 |
| 텍스처 | 모두 코드로 그립니다(`apps/client/src/world/atlas.ts`, 얼굴은 `character.ts`). 외부 이미지·다른 게임 자산 없음 |

텍스처 규칙: 색은 2장의 토큰 팔레트에서 파스텔로, 블록 하나에 4~6단계. 무늬는 부드러운 도형(판자는 두 장 + 못 자국, 양털은 펠트와 바늘땀, 지붕은 비늘 기와, 잔디 옆면은 크림처럼 물결진 테두리, 선반은 꿀단지 선반, 표지판은 말풍선). 잡음과 외곽선은 쓰지 않습니다. 멀리서 색 덩어리로 읽혀야 합니다.

### 6.2 캐릭터 — 둥근 장난감 인형

| 부위 | 크기(1/16m) | 비고 |
|---|---|---|
| 머리 | 11 × 10 × 10, 모서리 반지름 2.2 | 몸보다 넓게. 앞면에 얼굴, 위·뒤에 머리카락 껍데기 |
| 몸 | 8 × 8.4 × 5.6 + 아래 단 9.2 × 2.4 × 6.4 | A라인으로 퍼지는 옷단, 앞치마는 선택 |
| 팔 | 소매 3 × 4.4 × 3 + 팔 + 벙어리장갑 손 3.4 × 3 × 3.4 | 손에 든 아이템은 오른손 소켓 |
| 다리 | 3.6 × 6 × 3.8 + 둥근 신발 4.4 × 2.6 × 5.6 | |
| 전체 키 | ≈ 1.7m | 충돌 상자는 0.6 × 1.8 × 0.6m |

- 모든 부위는 모서리를 깎은 둥근 상자(정육면체 상자 6개 형식 아님)이고, 부위 행렬을 셰이더에 넘겨 인형 하나를 그리기 1번으로 그립니다.
- 얼굴은 큰 타원 눈 + 눈 반짝임, 볼 터치, 앞머리 물결 3개가 기본입니다. 입 모양 6종(닫힘, 작게, 크게, 넓게, 오, 웃음) × 눈 깜빡임 2 = 12칸을 처음에 한 장(4 × 3칸)에 그려 두고, 말할 때는 그 칸으로 텍스처 창만 옮깁니다(깜빡임·말하기에 텍스처 업로드 없음). 표정 8종(기본, 기쁨, 놀람, 곤란, 화남, 졸림, 추움, 더움)은 같은 시트를 늘려 붙입니다.
- 비율과 UV 배치는 다른 게임의 스킨 형식과 호환되지 않습니다. 외형을 구분하고 남의 스킨 자산이 섞여 들어오는 것을 막기 위함입니다.
- 애니메이션은 부위 회전만 씁니다: 서기, 걷기, 달리기, 점프, 낙하, 휘두르기, 놓기, 먹기·마시기, 말하기(손짓), 떨기, 축하, 쓰러짐, 앉기, 손 흔들기. 12프레임 기준 보간.
- 그림자는 발밑 원형 그림자를 인형 전체가 인스턴스 하나로 그립니다.
- 소켓 6개(`03`의 D1)의 장비는 인형 부위에 붙습니다.

### 6.6 기기 등급

| 항목 | 낮음 | 보통 | 높음 |
|---|---|---|---|
| 판정 기준 | 저가형 휴대폰·오래된 노트북 | 일반 노트북·태블릿 | 외장 그래픽 |
| 시야(청크) | 수평 4, 수직 3 | 6, 4 | 8, 5 |
| 해상도 배율 | 0.75 | 1.0 | 1.0 (최대 1440p) |
| 그림자 | 원형 | 원형 | 태양 그림자 |
| 파편 상한 | 200 | 400 | 600 |
| 목표 프레임 | 30 | 60 | 60 |
| 삼각형 예산 | 30만 | 60만 | 120만 |

처음 30초 동안 프레임 시간을 재서 등급을 자동으로 정하고, 설정에서 바꿀 수 있습니다.

구현(`apps/client/src/world/tiers.ts`, WP-004):

| 항목 | 낮음 | 보통 | 높음 |
|---|---|---|---|
| 블록 재질 | 꼭짓점 조명 셰이더 | 꼭짓점 조명 셰이더 | 램버트(태양 그림자 받음) |
| 안티에일리어싱 | 없음 | 없음 | MSAA |
| 구름 | 없음 | 인스턴스 1번 | 인스턴스 1번 |
| 동적 해상도 하한 | 0.5 | 0.6 | 0.75 |

- 그리기 횟수 예산은 장면당 50번 미만입니다. 청크는 4 × 4 청크 기둥을 한 영역 메시로 합치고(불투명 1 + 반투명 1), 인형·소품·구름·나비·그림자는 각각 한 번에 그립니다.
- 동적 해상도: 1초 평균 프레임 시간이 목표의 1.15배(그리고 30fps)를 넘으면 해상도를 10% 낮추고, 목표의 0.75배보다 빠르면 5% 올립니다. 등급의 배율보다 높이지 않고 하한보다 낮추지 않습니다.

등급은 음성 인식 경로도 정합니다(`02`의 6장, `04`의 4.4). 기기 내 WebGPU Whisper는 높음·보통에서만 올리고, 낮음(휴대폰·저사양 태블릿)은 모델 로딩을 아예 시도하지 않고 바로 서버 STT로 Opus 16kbps만 올립니다. iOS Safari는 탭 메모리가 빠듯해 높음에서만 올립니다. 구현은 `apps/client/src/stt.ts`의 `chooseSttPath(tier, hasWebGPU, isIOS)`와 `classifyDeviceTier`입니다. 등급 경계 수치(프레임 18ms/36ms, 메모리 4GB/8GB)는 위 표가 정성 기준만 주므로 구현에서 정한 값입니다.

### 7.2 터치

```text
+----------------------------------------------------------------+
| [메뉴] 08:45  코인 1,450        [지도] [거울] [시점]            |
| 배고픔 [######----]  목마름 [##--------]                        |
```

- 블록 부수기는 대상 블록을 길게 누르기, 놓기는 `놓기` 버튼입니다.

### 9.2 그래프 규칙

| 규칙 | 내용 |
|---|---|
| 선 | 주간값은 옅은 점, 4주 이동 평균은 3px 굵은 선 |
| 수업일 | 가로축에 짧은 세로 눈금과 작은 교사 아이콘 |
| 추정 | 점선 + "추정" 꼬리표. 실측과 같은 색을 쓰되 불투명도 50% |
| 세로축 | 양을 나타내는 그래프는 0에서 시작. 지수 그래프는 100 기준선 표시 |
| 이중 축 | 쓰지 않음. 단위가 다르면 작은 그래프를 나란히 |
| 누적과 변화 | 누적 곡선 옆에는 항상 주간 변화 그래프를 함께 배치 |
| 표본 부족 | 해당 주는 빈 원과 "표본 부족" |
| 숫자 옆 | 4주 전 대비 변화와 해석 한 줄 |
| 모드 색 | 자유 `brand`, 유도 `sun`, 낭독 `silver`, 회상 `grape` + 무늬 |
| 대화 밀도 띠 | 1분 = 폭 4px 칸, 위 줄 학생 `brand`, 아래 줄 교사 `sky`, 농도는 그 분의 발화 비율 |
| 클립 연결 | 그래프의 점이나 막대를 누르면 그 기간의 대표 클립 재생 |

## 10. 글의 어조

| 대상 | 어조 | 예 |
|---|---|---|
| 월드 안 목표 언어 | NPC 성격에 맞는 자연스러운 구어. 레벨에 맞는 길이 | "Coming right up!" |
| 월드 안 모국어 안내 | 짧은 해요체. 명령하지 않음 | "한 번 더 말해 볼까요?" |
| 실패 안내 | 탓하지 않음. 다음 행동을 알려 줌 | "잘 안 들렸어요. 마이크 가까이에서 다시 말해 주세요." |
| 보호자 화면 | 합쇼체. 숫자 먼저, 해석은 한 줄 | "한 번에 말하는 길이가 5.8단어에서 7.4단어로 늘었습니다." |
| 소개 사이트 | 해요체. 과장 금지, 보장 표현 금지 | `14` |

쓰지 않는 표현: "틀렸어요", "실패", "지금 구매하지 않으면", "다른 친구들은", 근거 없는 "최고"·"1위"·"보장".

## 11. 접근성

| 항목 | 기준 |
|---|---|
| 글자 크기 | 100~150% 조절. 150%에서도 대화창이 한 화면에 들어옴 |
| 색각 | 모든 의미 색에 모양·무늬·위치 병행. 색각 보정 팔레트 1종 |
| 소리 대체 | 모든 효과음에 화면 표시(방향 화살표와 아이콘), 모든 음성에 자막 |
| 조작 | 키 재배치, 누르고 있기 ↔ 켜고 끄기, 한 손 배치, 조준 보조 |
| 움직임 | 움직임 줄이기, 섬광 제한(5장) |
| 마이크 없이 | 조합판과 키보드로 진행(2성까지). 말하기가 어려운 날에도 놀 수 있음 |
| 읽기 | 읽기 쉬운 서체, 목표 문장 음절 구분 표시 옵션 |
| 화면 낭독기 | 대시보드와 소개 사이트는 표준 마크업과 대체 문구. 그래프마다 표 보기 제공 |
| 초점 | 키보드 초점 테두리 3px `sky-d`, 탭 순서는 시각 순서와 일치 |
