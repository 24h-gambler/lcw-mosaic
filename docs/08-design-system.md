# 08. 디자인 시스템

화면, 그래픽, 조작, 움직임의 규칙입니다. 소리는 `12`, 소개 사이트는 `14`에 있습니다. 토큰은 `packages/ui/tokens.ts` 한 곳에 두고 게임 HUD, 대시보드, 소개 사이트가 함께 씁니다.

## 1. 방향

| 항목 | 결정 |
|---|---|
| 한 줄 | 따뜻한 장난감 블록의 세계. 만지고 싶고, 부숴도 다시 서고, 말을 걸면 대답한다 |
| 느낌 | 밝다, 둥글지 않고 네모나다, 과하게 귀엽지 않다(12세가 유치하다고 느끼지 않는 선) |
| 3D | 전부 복셀. 지형·건물·캐릭터·아이템·가구가 같은 격자 감각을 공유 |
| 2D UI | 크림색 종이 위 굵은 테두리와 딱딱한 그림자. 블러와 유리 효과는 쓰지 않음 |
| 금지 | 사실적 폭력 표현, 붉은 피, 도박장 연출, 결제 압박 연출, 참조 게임의 고유 외형 모방 |

대상이 둘입니다. 플레이어(주로 아동·청소년)가 보는 게임 화면은 색이 풍부하고 반응이 큽니다. 보호자가 보는 대시보드와 리포트는 같은 토큰을 쓰되 차분하고 숫자가 먼저 보입니다.

## 3. 글자

| 용도 | 서체 | 비고 |
|---|---|---|
| 한국어 UI·본문 | Pretendard | SIL OFL. 숫자는 고정폭 옵션 사용 |

서체 라이선스는 착수 시 배포처에서 다시 확인합니다.

## 5. 움직임

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `fast` | 120ms, ease-out | 버튼, 슬롯 선택 |
| `base` | 200ms, ease-out | 패널 열기 |
| `slow` | 320ms, ease-in-out | 대화 카메라 전환(내 눈에서 NPC 얼굴로 시선이 옮겨 감) |
| `pop` | 240ms, 1.0 → 1.15 → 1.0 | 별 획득, 아이템 수령 |

- 화면 흔들림은 최대 0.3도, 300ms. 연속 폭발에서도 누적하지 않습니다.
- 섬광은 초당 3회 이하, 화면의 25% 이하 면적으로 제한합니다. 광과민성 발작 위험을 낮추기 위한 기준입니다.
- "움직임 줄이기" 설정이 켜져 있으면 흔들림·섬광·시차 효과를 끄고 전환을 페이드로 바꿉니다.

## 6. 3D 아트

### 6.1 격자와 밀도 — 실감 나는 블록 재질 (R2627)

블록 세계(부수고 짓기, `01`·`03`)는 그대로 두고, 재질과 빛을 실제처럼 그립니다. Dan 11-16 R2627("3d 환경자체가 리얼하지 않던데")로 예전의 파스텔 장난감 블록(32텍셀, 잡음 없음, 셰이더 베벨)을 바꿨습니다. 다른 복셀 작품의 16텍셀 최근접 픽셀 면과도 다르고, 어떤 작품의 자산·모양도 베끼지 않습니다(`15` 3장, AGENTS.md 4장 11).

| 대상 | 규격 |
|---|---|
| 지형·건축 블록 | 1m 정육면체, 면당 64 × 64 텍셀. 텍스처 배열 2장(색 sRGB + 재질 선형: 법선 x·y, 거칠기, 금속성), 선형 필터 + 밉맵 + 비등방(높음 8, 보통 2) |
| 표면 결 | 높이 지도에서 법선을 만들어 면마다 굴곡: 나뭇결과 판자 이음새, 벽돌 사이 줄눈, 둥근 자갈, 겹친 기와, 짠 양털, 긁힌·리벳 금속 |
| 반블록·계단·울타리 | 같은 텍셀 밀도의 부분 형태 |
| 아이템·가구·소품 | 둥근 모서리 상자 조각을 합친 한 덩어리(소품 하나 = 그리기 1번) |
| 캐릭터 | 6.2의 둥근 장난감 인형. 그리기 1번 |
| 텍스처 | 모두 코드로 생성합니다(`apps/client/src/world/textures.ts` → `atlas.ts`, 얼굴은 `character.ts`). 외부 이미지·다른 작품 자산 없음 |

텍스처 규칙: 색은 마을의 색(꿀 카페 노랑, 교역 상점 파랑, 붉은 지붕) 그대로, 실제 재료처럼 결·얼룩·패인 곳의 어두움을 넣습니다. 이어 붙여도 이음매가 없는 잡음(값 잡음·세포 잡음)을 씁니다. 거칠기로 재료를 구분합니다(물 0.04, 유리 0.05, 금속 0.4 안팎, 나무 0.7, 돌·흙 0.9 안팎).

### 6.2 캐릭터 — 둥근 장난감 인형

| 부위 | 크기(1/16m) | 비고 |
|---|---|---|
| 머리 | 11 × 10 × 10, 모서리 반지름 2.2 | 몸보다 넓게. 앞면에 얼굴, 위·뒤에 머리카락 껍데기 |
| 몸 | 8 × 8.4 × 5.6 + 아래 단 9.2 × 2.4 × 6.4 | A라인으로 퍼지는 옷단, 앞치마는 선택 |
| 팔 | 소매 3 × 4.4 × 3 + 팔 + 벙어리장갑 손 3.4 × 3 × 3.4 | 손에 든 아이템은 오른손 소켓 |
| 다리 | 3.6 × 6 × 3.8 + 둥근 신발 4.4 × 2.6 × 5.6 | |
| 전체 키 | ≈ 1.7m | 충돌 상자는 0.6 × 1.8 × 0.6m |

- 모든 부위는 모서리를 깎은 둥근 상자(정육면체 상자 6개 형식 아님)이고, 부위 행렬을 셰이더에 넘겨 인형 하나를 그리기 1번으로 그립니다.
- 얼굴은 큰 타원 눈 + 눈 반짝임, 볼 터치, 앞머리 물결 3개가 기본입니다. 입 모양 6종(닫힘, 작게, 크게, 넓게, 오, 웃음) × 눈 깜빡임 2 = 12칸을 처음에 한 장(4 × 3칸)에 그려 두고, 말할 때는 그 칸으로 텍스처 창만 옮깁니다(깜빡임·말하기에 텍스처 업로드 없음). 표정 8종(기본, 기쁨, 놀람, 곤란, 화남, 졸림, 추움, 더움)은 같은 시트를 늘려 붙입니다.
- 비율과 UV 배치는 다른 게임의 스킨 형식과 호환되지 않습니다. 외형을 구분하고 남의 스킨 자산이 섞여 들어오는 것을 막기 위함입니다.
- 애니메이션은 부위 회전만 씁니다: 서기, 걷기, 달리기, 점프, 낙하, 휘두르기, 놓기, 먹기·마시기, 말하기(손짓), 떨기, 축하, 쓰러짐, 앉기, 손 흔들기. 12프레임 기준 보간.
- 그림자는 발밑 원형 그림자를 인형 전체가 인스턴스 하나로 그립니다.
- 소켓 6개(`03`의 D1)의 장비는 인형 부위에 붙습니다.

### 6.3 조명과 하늘

| 요소 | 방식 |
|---|---|
| 기본 조명 | 태양 방향광 1 + 하늘 반구광. 블록 꼭짓점 주변 가림(AO)을 메싱 때 구움 |
| 복셀 빛 | 메싱 때 하늘빛(위가 트인 칸에서 아래·옆으로 줄며 퍼짐)과 블록 빛(횃불·랜턴·빛나는 블록, 0~15단계 BFS 전파)을 꼭짓점마다 구움(`voxel-light.ts`, Worker). 지붕 밑·가게 안은 어둡고 랜턴 곁은 주황빛. 꼭짓점 색 = (AO, 하늘빛, 블록 빛) |
| 재질(`materials.ts`) | 낮음 `fast`: 꼭짓점마다 빛. 보통 `fine`: 픽셀마다 법선 지도·거칠기 반사. 높음 `lit`: 물리 기반 재질 + 태양 그림자 |
| 물 | 물결 법선 두 겹, 프레넬 반사(하늘색), 태양 반짝임 |
| 바람 | 잎·풀·꽃 꼭짓점이 바람 표에 따라 흔들림(타일마다 세기) |
| 그림자 | 낮은 사양은 발밑 원형 그림자, 높은 사양은 태양 그림자 |
| 하늘 | 높이에 따른 산란 색, 해 주위 빛무리, 밤하늘의 별, 구름 색은 시각을 따름 |
| 안개 | 지평선 색 + 해 쪽은 햇빛 색이 섞인 산란 안개, 멀수록 옅은 대기 |

### 6.6 기기 등급

| 항목 | 낮음 | 보통 | 높음 |
|---|---|---|---|
| 판정 기준 | 저가형 휴대폰·오래된 노트북 | 일반 노트북·태블릿 | 외장 그래픽 |
| 시야(청크) | 수평 4, 수직 3 | 6, 4 | 8, 5 |
| 해상도 배율 | 0.75 | 1.0 | 1.0 (최대 1440p) |
| 그림자 | 원형 | 원형 | 태양 그림자 |
| 파편 상한 | 200 | 400 | 600 |
| 목표 프레임 | 30 | 60 | 60 |
| 삼각형 예산 | 30만 | 60만 | 120만 |

처음 30초 동안 프레임 시간을 재서 등급을 자동으로 정하고, 설정에서 바꿀 수 있습니다.

구현(`apps/client/src/world/tiers.ts`, WP-004):

| 항목 | 낮음 | 보통 | 높음 |
|---|---|---|---|
| 블록 재질 | 꼭짓점 조명 셰이더 | 꼭짓점 조명 셰이더 | 램버트(태양 그림자 받음) |
| 안티에일리어싱 | 없음 | 없음 | MSAA |
| 구름 | 없음 | 인스턴스 1번 | 인스턴스 1번 |
| 동적 해상도 하한 | 0.5 | 0.6 | 0.75 |

- 그리기 횟수 예산은 장면당 50번 미만입니다. 청크는 4 × 4 청크 기둥을 한 영역 메시로 합치고(불투명 1 + 반투명 1), 인형·소품·구름·나비·그림자는 각각 한 번에 그립니다.
- 동적 해상도: 1초 평균 프레임 시간이 목표의 1.15배(그리고 30fps)를 넘으면 해상도를 10% 낮추고, 목표의 0.75배보다 빠르면 5% 올립니다. 등급의 배율보다 높이지 않고 하한보다 낮추지 않습니다.

등급은 음성 인식 경로도 정합니다(`02`의 6장, `04`의 4.4). 기기 내 WebGPU Whisper는 높음·보통에서만 올리고, 낮음(휴대폰·저사양 태블릿)은 모델 로딩을 아예 시도하지 않고 바로 서버 STT로 Opus 16kbps만 올립니다. iOS Safari는 탭 메모리가 빠듯해 높음에서만 올립니다. 구현은 `apps/client/src/stt.ts`의 `chooseSttPath(tier, hasWebGPU, isIOS)`와 `classifyDeviceTier`입니다. 등급 경계 수치(프레임 18ms/36ms, 메모리 4GB/8GB)는 위 표가 정성 기준만 주므로 구현에서 정한 값입니다.

### 8.4 시작 화면과 내 월드 만들기

> Dan 11-16 14:3x 개정 — **가입이 먼저, 게스트는 체험만, 화면은 배울 언어로.**
> - 게스트(가입 안 한 기기)의 타이틀: `Sign up`(/signup) · `I have an account · Sign in`(/signup?mode=signin) · `Try it for 3 minutes`(/try) · 친구 월드 코드. 게스트는 월드를 만들지 않습니다(`makeMyWorld` 가 거절, 기기 월드 `lcw.myWorld` 없음).
> - 가입한 아이가 배울 언어를 아직 안 골랐으면(기기·서버 둘 다 없음) 맨 먼저 "What language do you want to learn?": English 만 열림, 日本語·中文·Español 은 Coming soon. 기기(`world/lang.ts`, `lcw.learnLang`)와 서버(`POST /v1/my-world/lang`)에 함께 둡니다. 새 기기에서는 서버 값을 따르고, 오프라인에서 고른 값은 다음에 조용히 올립니다.
> - 화면 글은 배울 언어(지금 English)로 나옵니다: 시작 화면·언어 단계·만들기·공개·패스 칩, 월드 HUD(`world/strings.ts` 표는 en·ko 쌍, 내보내는 이름의 `_KO` 는 호환용), 말풍선 이름, 선생님 이름표("Ms. Kim", 이름 없으면 "Teacher"). 한국어는 **켜고 끄는 도움말**(`lcw.helpKo`, 기본 꺼짐): 타이틀·언어 단계의 "한국어 도움말 켜기"로 켜면 영어 아래(HUD 는 " · " 뒤)에 한국어가 붙습니다.

- 다시 온 아이: 고르기 목록 없이 "〇〇로 가기" 한 버튼으로 내 월드에 바로 들어갑니다. 계절 날씨·하늘 시각·동물 친구가 월드에 그대로 보입니다. 수업 중에는 마을 기본 모습(낮, 날씨·동물 없음)으로 돌아갑니다.
- 가입한 아이의 기기는 선생님이 수업을 시작하면(`GET /v1/device/lesson`) 타이틀에서든 월드 안에서든 아무것도 누르지 않고 수업에 합류합니다(`POST /v1/device/lesson/join`, 코드 합류와 같은 학생 세션). 월드 안에서는 "선생님이 내 월드에 왔어요!" 알림이 4초 뜨고, 수업 레인의 선생님 존재 신호(`setTeacher({present, name})`)가 "함께"인 동안 선생님 아바타가 "〇〇 선생님" 이름표를 달고 아이 시야 안 몇 걸음 앞에 섭니다(NPC id `teacher`, `npcSay`·대화가 그대로 닿음).
- `/world/?code=`(옛 `/game/?code=` 포함) 주소는 타이틀을 거치지 않고 바로 들어갑니다(막지 않음).
- 공개 범위·PvP·정원·폭발 허용·방문자 권한 같은 고급 설정과 여러 월드 보관은 공개 서버(G08)·월드 초대와 함께 붙습니다.

## 10. 글의 어조

| 대상 | 어조 | 예 |
|---|---|---|
| 월드 안 목표 언어 | NPC 성격에 맞는 자연스러운 구어. 레벨에 맞는 길이 | "Coming right up!" |

| 소개 사이트 | 해요체. 과장 금지, 보장 표현 금지 | `14` |
