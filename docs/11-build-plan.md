# 11. 빌드 계획

혼자서 코딩 에이전트와 함께 만드는 순서입니다. 날짜보다 **통과 기준**이 우선입니다. 각 작업 패키지(WP)는 에이전트에게 한 번에 맡길 수 있는 크기로 잘랐고, 수용 기준은 자동 시험으로 확인할 수 있는 문장으로 썼습니다.

## 1. 순서의 원칙

1. **말하기 루프가 먼저.** 걷기, 쌓기보다 "말하면 물건이 생긴다"가 먼저 돌아야 이 제품입니다.
2. **첫 학생의 수업이 두 번째.** 수업 도구와 리포트가 있어야 과외에 쓸 수 있고, 그것이 첫 매출의 근거입니다.
3. **넓히는 것은 그다음.** 9개 섹터, 멀티, 공개 서버, 수직 차원은 한 섹터에서 루프가 검증된 뒤에 붙입니다.
4. **깨지지 않는 구조는 처음부터.** 구역, `setBlock` 단일 입구, 저널, 좌표계의 수직 범위는 M2에서 확정하고 이후 바꾸지 않습니다.

## 2. 마일스톤

| M | 이름 | 끝나면 할 수 있는 것 | 기간(`가정`, 1인 + 에이전트) |
|---|---|---|---|
| M0 | 뼈대 | 저장소, 배포, 빈 월드에 서 있기 | 1주 |
| M1 | 말하면 생긴다 | 광장과 카페에서 걷고, 말로 주문하고, 마시기 | 3~4주 |
| M2 | 쌓고 부수고 남는다 | 블록 건축, 저장, 폭발·물·로켓, 구역 보호 | 3주 |
| M3 | 수업 | 디렉터 콘솔, 수업 창문, 리포트, 학부모 대시보드 | 4주 |
| M4 | 도시 전체 | 9개 섹터 생성, 상점 4종, 경제, 복습 전 구간, 직업, 법정, 복권 | 5~6주 |
| M5 | 함께 | 멀티 룸, 말풍선, 게스트 패스, 다중 월드, 공개 서버, 전투 | 5주 |
| M6 | 만들고 오른다 | AI 제작 5종과 검문, 주민 입주, 수직 밴드 | 5주 |
| M7 | 판다 | 소개 사이트, 체험 씬, 쇼룸, 좌석 관리, 운영 확인함 | 3주 |

첫 학생과의 수업은 M3이 끝나는 시점부터 가능합니다(약 3개월, `가정`). 그 전에는 M1 빌드로 수업 일부를 시험해 볼 수 있습니다.

## 4. 완료의 정의

WP 하나는 다음을 모두 만족해야 끝난 것입니다.

1. 수용 기준이 자동 시험으로 들어가 있고 통과한다.
2. 관련 스펙 문서와 어긋나는 값이 없다. 값을 바꿨다면 문서를 함께 고쳤다.
3. 형식 검사와 타입 검사가 통과한다.
4. 새 외부 의존성을 넣었다면 이유와 크기를 PR에 적었다.
5. 금지 사항(`AGENTS.md`)을 어기지 않았다.
