# 13. 파괴 물리와 월드 보존

물폭탄, 로켓, 다이너마이트를 얼마든지 써도 월드가 망가지지 않아야 합니다. 이 문서는 그 규칙과 상한, 그리고 규칙을 코드로 옮겨 돌려 본 결과를 적습니다.

먼저 범위를 분명히 합니다. 3D 게임 자체는 아직 만들어지지 않았으므로, 여기서 확인한 것은 **파괴 규칙의 참조 구현**입니다(코드 전문은 `17-reference-destruction-code.md`). 렌더링, 네트워크, 실제 기기 성능은 이 확인에 들어 있지 않습니다. 게임을 만들 때는 이 커널을 `packages/destruction`으로 옮기고 같은 시험을 CI에 겁니다.

## 1. "깨진다"의 정의

| 유형 | 예 | 막는 수단 |
|---|---|---|
| 진행 불가 | 스폰이 묻힘, 필수 상점으로 가는 길이 끊김, 광장이 사라짐 | 보호 코어, 도로 불가침 |
| 복구 불가 | 도시가 폐허로 남음, 남의 집이 날아감 | 임시층 자동 복구, 부지 권한, 저널 되감기 |
| 폭주 | 연쇄 폭발·물·투사체가 끝없이 불어나 멈춤 | 대기열·개수·틱당 예산 상한 |
| 수치 오염 | NaN 좌표, 무한대 속도, 경계 밖 좌표 | 입구 검사, 속도 제한, 구조 이동 |
| 끼임·추락 | 복구되는 벽 속에 갇힘, 월드 밖으로 떨어짐 | 복구 연기와 밀어 올리기, 경계 구조 |
| 저장 비대 | 편집이 쌓여 저장이 한도를 넘음 | 영구층 상한, 초과분은 임시층 |

## 2. 구역

모든 칸은 네 구역 중 하나에 속하고, 블록을 바꾸는 모든 경로(손, 도구, 폭발, 능력 태그)는 `setBlock` 하나를 지납니다. 구역 판정은 좌표만으로 하는 순수 함수입니다.

| 구역 | 범위 | 블록 변경 | 폭발 |
|---|---|---|---|
| 보호 코어 | 광장, 스폰, 도로(노면 아래 2칸 ~ 위 4칸), 필수 상점의 거점, 엘리베이터, 최하층 암반, 월드 경계 | 불가 | 광선이 여기서 멈춤. 그을음 자국만 남음 |
| 도시 | 도시 프리팹 건물과 주변 2칸 | 임시층에 기록, 60초 뒤 원래대로 | 부서지되 60초 뒤 복구 |
| 내 부지 | 소유자의 부지 | 소유자와 허가받은 사람만, 영구 | 소유자와 허가받은 사람의 폭발만 유효 |
| 자유 | 그 밖의 지상, 지하, 하늘섬 | 영구(저장 상한 내) | 영구 |

- 도로를 보호 코어에 넣은 것이 핵심입니다. 도로 노면과 그 위 4칸에는 누구도 블록을 놓거나 부술 수 없으므로, 스폰에서 9개 섹터 거점까지 걸어가는 길은 어떤 경우에도 유지됩니다.
- 필수 상점의 건물은 도시 구역이라 부서질 수 있지만, 상인과 계산대 자리(거점)는 보호 코어입니다. 가게가 날아간 60초 동안에도 상인은 그 자리에서 주문을 받습니다.
- 도로 아래 3칸부터는 자유 구역이므로 땅굴은 팔 수 있습니다.
- 플레이어가 한 칸씩 쌓은 건물은 내 부지 안에 있으므로, 남의 폭발·로켓으로는 한 칸도 깨지지 않습니다.

## 3. 아이템별 규칙

| 아이템 | 동작 | 월드에 남는 것 | 상한 |
|---|---|---|---|
| 다이너마이트 | 위력 4 폭발. 다른 폭발에 닿으면 0.5~1.5초 뒤 연쇄 | 구역 규칙에 따름 | 위력 6, 폭발당 1,500블록 |
| 연쇄 폭발 | 대기열에 쌓여 틱당 2개씩 처리 | | 대기 64개. 넘치는 것은 불발(터지지 않고 사라짐) |
| 물폭탄 | 착탄점에 유체 칸 생성, 밀어내기, 불 끄기 | **블록을 바꾸지 않음.** 유체는 20초 뒤 증발 | 폭탄당 256칸, 월드 전체 4,096칸 |
| 로켓 | 직선 비행, 닿으면 위력 3 폭발 | 구역 규칙에 따름 | 초속 40m, 수명 6초, 1인 4발, 월드 32발 |
| 폭죽·제트 추진 | 플레이어에게 충격량 | 없음 | 속도 초속 60m로 제한 |
| 불 | 8초 지속되는 임시 효과 | **번지지 않고 블록을 태우지 않음** | |

**일부러 넣지 않은 것**

| 넣지 않는 기능 | 이유 |
|---|---|
| 스스로 불어나는 물(수원 블록) | 참조한 블록 게임에서는 물이 수원에서 7칸까지 퍼지고, 수원 둘과 맞닿은 빈 칸이 새 수원이 되어 무한히 늘 수 있음. 여기서는 유체가 수명을 가진 임시 칸이고 새 수원을 만들지 않음. 연못은 정지한 물 블록을 한 칸씩 놓아 만듦 |
| 번지는 불 | 건물 전체를 태우는 연쇄를 막을 수 없음 |
| 떨어지는 블록(모래·자갈 낙하) | 대량 낙하가 연산을 폭주시키고 지형을 예측 불가하게 바꿈 |
| 회로·피스톤류 | 무한 반복 장치를 만들 수 있음 |
| 블록·아이템 복제가 가능한 장치 | 경제 붕괴 |

## 4. 폭발 계산

참조한 블록 게임의 공개된 광선 방식을 따르되, 난수를 시드로 고정하고 상한을 덧붙였습니다.

1. 폭발 중심에서 16 × 16 × 16 격자의 겉면 점을 향해 광선 1,352개를 쏩니다.
2. 광선의 세기는 `위력 × (0.7 ~ 1.3)`에서 시작합니다. 배율은 `(위치, 틱, 월드 시드)`로 만든 난수라서 같은 입력은 같은 구덩이를 만듭니다.
3. 0.3칸씩 전진하며 매 걸음 0.225를 잃고, 공기가 아닌 칸에서는 `(폭발 저항 + 0.3) × 0.3`을 더 잃습니다.
4. 세기가 남아 있으면 그 칸을 부술 목록에 넣습니다. 보호 코어, 권한 없는 부지, 깨지지 않는 블록을 만나면 그 광선은 끝납니다.
5. 목록이 1,500칸에 닿으면 계산을 멈춥니다.
6. 목록의 칸은 블록 연산 대기열에 들어가고, 틱당 2,000칸씩 `setBlock`을 거쳐 적용됩니다.

멀티플레이에서는 계산을 기기에서 하고 서버(`WorldDO`)는 가벼운 것만 확인합니다: 칸 수가 상한 이하인지, 모든 칸이 중심에서 위력에 맞는 반경 안인지, 보호 코어나 권한 없는 부지의 칸이 없는지, 행위자의 초당 폭발 횟수가 한도 안인지.

## 5. 상한표

참조 코드의 `CFG`와 같은 값입니다. 문서와 코드가 다르면 코드가 기준입니다.

| 항목 | 값 | 넘으려 할 때 |
|---|---|---|
| 폭발 위력 | 6 | 6으로 깎음 |
| 폭발당 블록 | 1,500 | 계산 중단 |
| 폭발 대기열 | 64 | 불발 |
| 틱당 폭발 처리 | 2 | 다음 틱으로 |
| 행위자당 폭발·물폭탄 | 초당 4회 | 거절 |
| 틱당 블록 연산 | 2,000 | 다음 틱으로 |
| 틱당 복구 | 1,000 | 다음 틱으로 |
| 임시층 칸 | 60,000 | 거절 |
| 영구층 칸 | 저장 20MB에서 역산(참조 실행은 200,000) | 이후 편집은 임시층으로 |
| 유체 칸 | 폭탄당 256, 전체 4,096 | 더 퍼지지 않음 |
| 유체 수명 | 20초 | 증발 |
| 유체 갱신 | 5틱마다 512칸 | 다음 주기로 |
| 투사체 | 1인 4, 전체 32 | 거절 |
| 투사체 속도·수명 | 틱당 2칸(초속 40m), 120틱 | 깎음, 소멸 |
| 투사체 이동 | 0.25칸 간격으로 훑음 | 얇은 벽 통과 불가 |
| 플레이어 속도 | 틱당 3칸(초속 60m) | 깎음 |
| 임시층 복구 시간 | 60초 | |

## 6. 플레이어 보호

| 상황 | 처리 |
|---|---|
| 좌표나 속도가 NaN·무한대 | 스폰으로 구조 |
| 월드 경계나 최하층 밖 | 스폰으로 구조 |

## 7. 확인한 것과 확인하지 않은 것

### 7.1 방법

| 종류 | 내용 |
|---|---|
| 지정 시나리오 | 최악의 경우를 골라 만든 16개 |
| 무작위 실행 | 여러 명이 폭발·연쇄·물폭탄·로켓·블록 설치·채굴·충격을 무작위로 섞어 실행. 일부는 일부러 망가뜨린 입력(NaN, 무한대, 경계 밖, 위력 10억). 매 틱 불변식 검사 |
| 결함 주입 | 방어 장치를 하나씩 끄고 시험이 그 결함을 잡아내는지 확인 |

검사하는 불변식: 스폰이 비어 있고 발밑이 단단함, 스폰에서 9개 거점까지 도로로 연결됨, 보호 코어의 블록이 처음과 같음, 보호 코어에 영구·임시 편집이 없음, 유체·투사체·대기열·임시층·영구층이 상한 이하, 틱당 연산이 예산 이하, 폭발당 블록과 위력이 상한 이하, 모든 플레이어의 좌표가 유한하고 월드 안이며 블록 속에 있지 않음.

## 8. 이식할 때 지킬 것

1. 블록을 바꾸는 코드 경로는 `setBlock` 하나뿐이어야 합니다. 린트 규칙으로 청크 배열 직접 쓰기를 금지합니다.
2. 구역 판정은 좌표만 받는 순수 함수로 두고, 월드젠이 만든 구역표(광장, 도로, 거점, 프리팹 상자, 부지)를 읽습니다. 참조 코드의 좌표는 예시이고 실제 배치는 `03`의 3.3을 따릅니다.
3. 임시층 복구는 참조 코드처럼 전체를 훑지 말고 만료 시각별 묶음으로 관리합니다.
4. 능력 태그는 `explode`, `waterBomb`, `rocket`, `impulse` 네 함수만 부를 수 있습니다. 새 효과가 필요하면 커널에 함수를 추가하고 상한과 시험을 함께 넣습니다.
5. 시나리오·무작위·결함 주입 세 시험을 CI의 필수 단계로 둡니다. 결함 주입이 하나라도 "검출 안 됨"이면 실패로 처리합니다.
6. 화면 쪽 상한(`08`의 6.5, 6.6)은 별도로 지킵니다: 파편 600, 틱당 메시 재생성 청크 4개, 조명 갱신 예산.
