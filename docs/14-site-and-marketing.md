# 14. 소개 사이트와 소개 영상

무료 계정이 없으므로 소개 사이트가 영업의 전부입니다. 학부모와 학생은 원하는 것이 다르므로 한 페이지에서 설득하지 않고, 같은 사이트 안에 **두 개의 입구**를 둡니다.

## 1. 원칙

1. **보여 주고, 주장하지 않는다.** 실제 화면, 실제 그래프, 실제 음성 견본으로 설득합니다.
2. **보장하지 않는다.** "몇 주 만에 유창", "성적 향상 보장" 같은 표현은 쓰지 않습니다. 근거를 댈 수 없는 최상급 표현도 쓰지 않습니다.
3. **지어낸 후기는 없다.** 후기 자리는 실제 이용자의 동의를 받은 글로만 채웁니다. 그 전에는 자리를 비워 둡니다.
4. **아이에게 팔지 않는다.** 학생 페이지에는 가격과 결제 버튼이 없습니다. "부모님께 보내기"만 있습니다.
5. **다른 게임의 이름을 빌리지 않는다.** 광고 문구와 검색 키워드에 타사 게임 상표를 쓰지 않습니다.

## 6. 요금 페이지 (W05)와 자주 묻는 질문

요금표는 `01`의 4장과 같습니다. 표 아래에 세 줄을 둡니다: 모든 좌석은 전 기능, 쓰기 전·결제 후 7일 안 환불, Duo는 가족이 아니어도 됨. 환불 안내 바로 옆에 "결제 전에 3분 체험과 친구 초대(30분)로 먼저 써 보세요"를 둡니다.

| 질문 | 답의 요지 |
|---|---|
| 무료로 해 볼 수 있나요 | 가입 없이 3분 체험이 있고, 이용 중인 친구가 있으면 30분 초대권으로 함께 해 볼 수 있습니다. 환불은 결제 후 7일 안에, 좌석을 쓰기 시작하기 전까지만 되므로 먼저 써 보시길 권합니다 |
| 몇 살부터 할 수 있나요 | 권장 대상과 보호자 동의 절차 안내 |
| 정말 영어가 늘까요 | 약속 대신 측정 방식을 설명합니다. 대본 없는 발화의 양과 길이를 매주 보여 드리고, 늘지 않으면 늘지 않은 대로 보입니다 |
| 놀기만 하게 되지 않을까요 | 물건을 얻는 길이 전부 말하기라는 점, 주간 요약, 플레이 시간 안내 |
| 아이 목소리는 어떻게 되나요 | 저장은 동의한 경우에만, 보관 기간, 삭제 방법, 외부 공개 없음 |
| 모르는 사람과 대화하나요 | 공개 서버는 보호자가 허용한 경우에만, 대화는 걸러진 말풍선으로만, 실제 음성은 승인한 친구와 수업에서만 |
| 어떤 기기에서 되나요 | 브라우저에서 실행, 권장 사양, 헤드셋 권장 |
| 과외를 받지 않아도 되나요 | 됩니다. 과외는 선택이고 수업 창문과 수업 리포트가 더해집니다 |
| 다른 언어도 있나요 | 현재 제공 언어와 준비 중인 언어 |
| 해지하면 월드는 어떻게 되나요 | 30일 읽기 전용, 이후 보관, 음성 처리 방침 |

### 결제 단계 (`/pricing#plans`, R326)

무료 3분 체험이 끝난 아이 기기의 카드('보호자와 이용권 고르기')와 `/try` 끝 화면이 `/pricing?from=world|try#plans` 로 보냅니다. 아이 화면에는 가격·결제 낱말이 없고, 가격은 이 어른 페이지에만 있습니다(AGENTS 4.9).

| 단계 | 화면 | 서버 |
|---|---|---|
| 1 고르기 | Solo·Duo × 월·연, 금액은 `GET /v1/billing/config`(서버 정가 `PLAN_PRICES_KRW`, 브라우저 1시간 캐시) | — |
| 2 보호자 정보 | 이름, 연락처(휴대전화 또는 이메일), 환불 조건 확인 체크("이용을 시작하면 환불되지 않습니다") | — |
| 3 주문 | 시험 모드(계좌이체 주문): '주문 넣기 (계좌이체)', 띠 "카드 결제 준비 중 — 지금은 계좌이체로 받아요" / 운영: '결제하기' → 토스 카드 창 | `POST /v1/billing/checkout` — 금액은 서버가 정함(본문에 금액이 있으면 400), 이 브라우저의 아이 기기 토큰이 있으면 그 아이에게 묶음, 주소당 시간당 6건 |
| 4 끝 | 시험 모드: 주문 번호 + "선생님이 입금 계좌를 연락처로 보내 드려요" / 운영: 토스가 `?pay=done&paymentKey&orderId&amount` 로 돌려보내면 확인 | `POST /v1/billing/confirm` — 금액이 주문과 다르면 거절, 토스 승인(비밀 키 Basic) 뒤 Solo + 묶인 아이 + 보호자 있음이면 좌석 즉시 발급(`issueSeats`, 운영자 발급과 같은 표), 이미 좌석이 살아 있으면 같은 결제로 그 좌석을 기간만큼 연장(`extendSeatPaid`, 응답 `seat:'seat_extended'`, 화면 '이용 중인 좌석이 그만큼 늘어났어요'), 아니면 확인함. 토스 5xx·`PROVIDER_ERROR` 는 502 `toss_unavailable` 로 주문을 결제 가능 상태로 두고, 두 탭이 같은 결제를 동시에 확인해도 좌석은 한 번만 엽니다 |

- 모드는 배포가 정합니다: `TOSS_CLIENT_KEY`·`TOSS_SECRET_KEY` 비밀이 둘 다 있으면 운영(live), 아니면 시험(test). 지금은 시험 모드입니다 — 회사 도메인의 토스 가맹(MID) 승인이 아직 없어서, 실결제를 켜는 것은 운영자 결정(가맹 승인 + 두 비밀 등록)입니다.
- 주문의 이름·연락처는 끝난 주문(좌석 발급·실패·버려진 결제 대기)이면 180일 뒤 지웁니다(`sweepBillingContacts`, 매시 좌석 알림과 함께). 입금 대기·결제 완료(좌석 발급 필요)는 운영자가 연락해야 하니 남깁니다.
- 시험 모드 주문은 좌석을 스스로 열지 않습니다(누구나 공짜 좌석을 여는 구멍). 운영자 확인함(`/seats`, '온라인 주문')에 '입금 확인 대기'로 뜨고, 입금을 보면 아래 좌석 발급으로 엽니다.

## 8. 체험 씬 (W06)

| 항목 | 내용 |
|---|---|
| 구성 | 광장 한 구역과 카페 한 곳, 손 흔드는 주민 몇 명 |
| 흐름 | 시작 버튼(소리 켜기) → 10초 이동 안내 → 카페 → 마이크 허용 → 음성 주문 1회 → 슬롯 수령 → 마시기 → "이 월드를 저장할까요" |
| 기술 | 서버 룸 없음. 문장 뱅크와 브라우저 음성 인식으로 동작. 마이크를 허용하지 않으면 조합판으로 진행 |
| 안내 | 시작 전 한 줄: 체험에서는 브라우저의 음성 인식을 쓰며 음성이 저장되지 않는다는 점 |
| 앱 내 브라우저 | 카카오톡(`KAKAOTALK`), 인스타그램, 페이스북(`FBAN`/`FBAV`), 네이버(`NAVER(inapp`), 라인, 다음, 사파리 없는 iOS WebView를 UA 문자열로 감지(순수 함수 `detectInAppBrowser`). 감지되면 화면 맨 위에 "크롬/사파리로 열기" 띠를 띄운다. 안드로이드는 `intent://` 크롬 열기 링크, iOS는 안내 문구와 링크 복사 단추. 인스타·카카오톡 링크 유입이 많아 첫 화면에서 막히지 않게 하려는 장치 |
| 음성 인식 미지원 | `SpeechRecognition`/`webkitSpeechRecognition`이 없으면(iOS 앱 내 브라우저는 생성자가 있어도 없는 것으로 취급) 단어 카드를 눌러 3성 문장을 조립한 뒤 말하게 한다. 이 경로는 음량과 길이만 잰다: `getUserMedia` + `AnalyserNode`로 음성 같은 에너지(RMS 0.04 이상, 400ms 이하 끊김은 이어 붙임)가 800ms 이상 이어지면 통과(상수 `TRY_SPEECH_MIN_MS`)하고 아이 자신의 녹음을 다시 들려준다. 서버 호출 없음, 녹음은 이 탭 안에서만 쓰고 저장하지 않는다. `getUserMedia`도 없으면 단어 카드 조립만으로 진행 |
| 로딩 예산 | 초기 스크립트 1.5MB 이하(압축), 첫 장면 자산 4MB 이하 |
| 끝 화면 | 학부모용 버튼, 성인 학습자용 버튼, 과외 문의 버튼 |

## 9. 표현 페이지 (W07)

- 뱅크의 맥락·의도 하나가 페이지 하나입니다(예: 카페에서 주문하기).
- 구성: 상황 그림, 1~3성 문장 예시와 듣기, 모국어 설명, 자주 틀리는 부분, [이 장면 해 보기] 버튼.
- 검색에 노출되는 것은 이 글 페이지이고, 3D 화면은 버튼을 눌렀을 때만 불러옵니다.
- 제목과 설명에 타사 상표를 넣지 않습니다.

## 11. 기술과 측정

| 항목 | 기준 |
|---|---|
| 구현 | 정적 페이지. 3D는 `/try`와 `/s`에서만 불러옴 |
| 성능 | 최대 콘텐츠 표시 2.5초 이내(보통 휴대폰), 페이지 무게 600KB 이하(영상 제외) |
| 영상 | 15초 반복은 1.5MB 이하, 화면에 보일 때만 재생 |
| 공유 미리보기 | 페이지별 제목·설명·대표 그림. 쇼룸은 월드 썸네일 |
| 접근성 | `08`의 11장 |
| 측정 | 쿠키 없는 방문 통계. 기록하는 사건: 입구 선택, 체험 시작, 마이크 허용, 주문 완료, 저장 제안 응답, 부모님께 보내기, 요금 페이지 도달, 상담 신청 |
| 금지 | 아동 대상 맞춤 광고, 제3자 추적 스크립트 |
