# 16. 안전·개인정보·규제 점검표

이 문서는 법률 자문이 아닙니다. 설계에 미리 반영한 내용과, 출시 전 전문가 확인이 필요한 쟁점을 한곳에 모은 목록입니다. "확인 필요"로 표시한 항목은 제가 판단할 수 없는 것들입니다.

## 1. 아동 안전 설계 요약

| 위험 | 설계상 대응 |
|---|---|
| 낯선 성인과의 접촉 | 자유 텍스트·음성 채팅 없음. 말풍선은 인식 → 목표 언어 판별 → 필터를 거친 문장만. 실제 음성은 보호자가 승인한 친구와 수업에서만 |
| 개인정보 노출 | 말풍선 필터가 전화번호·주소·계정 아이디 형태를 차단. 닉네임은 실명 금지 안내와 필터 |
| 공개 서버 | 미성년 계정은 보호자의 동의가 있고 "모두" 대상인 서버만. 방문자 기본 권한은 상호작용까지 |
| 괴롭힘 | 신고 3건이면 말풍선 자동 정지, 소유자의 추방·차단, 쓰러져도 잃는 것 없음, PvP 기본값 꺼짐 |
| 구매 압박 | 아이 화면에 가격·결제·기한 없음. 현금으로 사는 재화 없음. 확률형 보상은 게임 내 코인으로만 |
| 과몰입 | 플레이 시간 안내 설정, 연속 기록 압박 알림 없음, 미접속 알림은 보호자에게 주 1회 상한 |
| 부적절한 생성물 | AI는 제한된 명세만 제안, 이름·설명 필터, 공개되는 직접 제작물은 자동 분류, 불확실하면 비공개 |
| 외부인의 관찰 | 쇼룸은 정적 스냅샷. 실시간 위치·음성·실명 없음. 기본 비공개 |
| 수업 참관 | 참관자는 해당 학생의 보호자뿐. 교사에게 항상 표시, 학생에게 수업 시작 시 안내 |

## 3. 동의 화면에 들어갈 것

| 동의 | 설명 문구의 요지 | 거부하면 |
|---|---|---|
| 필수: 서비스 이용 | 계정, 플레이 기록, 발화 전사문과 지표 | 이용 불가 |
| 선택: 음성 저장 | 아이의 발화 음성을 저장해 보호자가 다시 들을 수 있게 함. 보관 기간과 삭제 방법 | 전사문과 지표만 남고 육성 클립 없음 |
| 선택: 수업 창문 | 수업 중 보호자가 실시간으로 들을 수 있게 함 | 수업 창문 없음 |
| 선택: 쇼룸 공개 | 아이 월드의 정지 화면을 링크로 공유 | 공유 불가 |
| 선택: 공개 서버 | 다른 사람이 연 공개 월드에 들어갈 수 있게 함 | 비공개·초대 월드만 |
| 선택: 친구 음성 | 승인한 친구와 실제 음성으로 대화 | 말풍선만 |

각 동의는 따로 켜고 끌 수 있어야 하고, 한 화면에서 전부 켜는 버튼은 두지 않습니다.

## 4. 필터와 신고의 동작

| 단계 | 내용 |
|---|---|
| 입력 필터 | 금칙어, 개인정보 형태, 목표 언어 비율. 걸리면 전송하지 않고 본인에게만 사유 표시 |
| NPC의 대응 | 부적절한 요청에는 NPC가 유머로 되묻고 대화를 원래 주제로 돌림 |
| 신고 | 대상과 사유 선택. 직전 말풍선 기록이 함께 올라감 |
| 자동 조치 | 서로 다른 3명의 신고로 말풍선 정지(해당 월드), 확인함 등록 |
| 운영자 조치 | 해제, 정지 유지, 공개 서버 입장 제한, 보호자에게 통지 |
| 기록 | 조치 내역 보관 |

## 5. 출시 전 확인 순서

1. 가족 단위 비공개 운영(과외 학생과 지인): 1~7번 항목의 문구와 절차를 전문가에게 확인받습니다.
2. 좌석 판매 시작 전: 8~13번.
3. 공개 서버와 쇼룸을 열기 전: 1장의 대응이 실제로 동작하는지 시험하고 14~19번을 확인합니다.
4. 다른 언어·다른 나라로 넓히기 전: 20번.
