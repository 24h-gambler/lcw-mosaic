# 21. 제품 용어집

- 기준일: 2026-11-16
- 이 파일이 사용자에게 보이는 낱말의 기준입니다. 사이트·월드 UI·보호자 화면·리포트·메일·스토어 설명이 모두 따릅니다.
- 금지어 시험은 운영·통합 레인이 맡습니다. 사용자 문구에서 '게임'·game을 막고, 이 파일과 같은 목록을 씁니다.
- `l1`(화면 언어)이 늘면 언어마다 열을 더합니다(`20` 1장).

## 1. 쓰지 않는 낱말

| 쓰지 않는 말 | 대신 쓰는 말 | 이유 |
|---|---|---|
| 게임, game, 게이머 | 월드, 마을, 놀이, 플레이어 | Dan 지시(2026-11-16). 보호자가 '게임 시간'으로 읽고 학습 시간에서 빼는 것을 막습니다 |
| 게임 화면 | 실제 화면, 월드 화면 | 캡처 설명은 '실제 화면 · 시연' |
| 게임 재화, 게임 머니 | 코인 | 코인은 월드 안에서만 쓰고 현금으로 사지 않습니다 |
| 게임 시간 | 화면 시간, 플레이 시간 안내 | |
| 레벨업, 퀘스트(아이 화면 밖) | 문장이 자란다, 할 일 | 보호자에게는 결과(말한 양·길이)로 말합니다 |
| 정답, 오답 | 별 1·2·3개, 다시 말해 보기 | 틀렸다고 하지 않습니다(`04`) |
| 시험, 평가(아이 화면) | 말해 보기, 연습 | 아이 화면에서는 쓰지 않습니다. 보호자 리포트에서는 '측정'을 씁니다 |
| 결제, 가격, 기한(아이 화면) | — | 아이 화면 금지(AGENTS.md 4.9). 사이트 요금 페이지와 보호자 화면에만 씁니다 |
| 낯선 사람, 랜덤 친구 | 초대한 친구 | 친구는 초대 코드로만 들어옵니다(`16`) |

## 2. 제품 낱말

|---|---|---|---|

## 3. 대표 문구 제안 ('게임' 없이)

운영·통합 레인이 `copy.ts`의 '게임'을 '월드'로 바꾸는 중입니다(2026-11-16). 아래는 대표 자리의 문구 제안입니다. 같은 자리를 그쪽에서 이미 고쳤다면 그쪽을 기준으로 하고, 이 표는 다음 문구를 쓸 때의 기준으로 씁니다.

| 자리 | 지금 | 제안 |
|---|---|---|
| 첫 화면 위 작은 글(`HERO.eyebrow`) | 영어로 말해야 물건이 생기는 3D 블록 게임 | 영어로 말해야 물건이 생기는 3D 블록 월드 |
| 첫 화면 제목 | 말하면 생기는 세계 | 그대로 |
| `/` 메타 설명 | 영어로 말해야 물건이 생기는 3D 블록 게임. 설치·가입 없이 5분 체험. | 영어로 말해야 물건이 생기는 3D 블록 월드. 설치·가입 없이 3분 체험. |
| 기본 셸 제목(`index.html`) | LCW — 말하면 생기는 3D 영어 게임 | LCW — 말하면 생기는 세계 |
| 기본 셸 설명 | 영어로 말해야 물건이 생기는 3D 블록 게임. 아이가 영어로 말하러 들어오는 세계. | 영어로 말해야 물건이 생기는 3D 블록 월드. 아이가 영어로 말하러 들어오는 세계. |
| 공유 카드 `og:image:alt` | {제목} — 실제 게임 화면 | {제목} — 실제 화면 |
| 사진·영상 꼬리표 | 실제 게임 화면 · 시연 | 실제 화면 · 시연 |
| 부모님께 보내기 문장(`SHARE.text`) | 영어로 말해야 물건이 생기는 게임이래요. 한번 봐 주세요! | 영어로 말해야 물건이 생기는 월드래요. 한번 봐 주세요! |
| 보호자 페이지 첫 문장 | 게임하는 줄 알았는데, 들어 보니 말을 하고 있습니다. | 노는 줄 알았는데, 들어 보니 영어로 말하고 있습니다. |
| 시간 걱정 제목 | 게임 시간이 걱정되신다면 | 화면 시간이 걱정되신다면 |
| 자주 묻는 질문 | 게임만 하게 되지 않을까요? | 놀기만 하게 되지 않을까요? |
| 코인 설명 | 코인은 게임 안에서만 쓰는 돈이에요. | 코인은 월드 안에서만 쓰는 돈이에요. |
| 약관 요약 '서비스' | 영어 말하기 게임과 보호자 화면, 선택형 과외 수업 도구 | 영어 말하기 월드와 보호자 화면, 선택형 과외 수업 도구 |
| 개인정보 '쓰는 곳' | 게임 진행, 성장 그래프와 리포트, 수업 진행 | 월드 이용, 성장 그래프와 리포트, 수업 진행 |
| 스토어 짧은 설명(예정) | — | 영어로 말해야 물건이 생기는 3D 블록 월드. 말한 문장이 길수록 더 많이 얻어요. |

'놀이', '놀다'는 쓸 수 있습니다. 아이에게는 재미를, 보호자에게는 '말한 시간'을 말합니다.

## 4. 이 파일을 고칠 때

- 새 낱말을 사용자 문구에 처음 쓰기 전에 2장에 한 줄 더합니다.
- 1장에 낱말을 더하면 금지어 시험 목록(운영·통합 레인 소유)도 같은 PR에서 고칩니다.
