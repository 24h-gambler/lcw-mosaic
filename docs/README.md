## 5. 판단을 맡기신 항목

**무료 이용 범위.** 무료 계정을 두지 않았습니다. 무료 인프라의 일일 한도를 유료 사용자와 수업이 먼저 써야 하고, 미성년자 무료 계정은 보호자 동의 절차만 늘리며, 과외와 묶인 상품은 돈을 내는 것이라는 인식이 가치를 올립니다. 체험이 전혀 없으면 구매가 일어나지 않으므로 서버 비용이 거의 없는 체험 세 가지를 둡니다.

**기능 제한.** 두지 않습니다. 요금제는 좌석 수와 결제 주기만 다릅니다.

**조르기 설계.** 같이 놀아 본 친구가 갖고 싶어지는 구조는 살렸습니다. 다만 아이 화면에는 "부모님께 소개 보내기" 버튼만 두고 가격·기한·반복 팝업은 넣지 않았습니다. 미성년자 대상 구매 압박은 규제와 평판 양쪽에서 위험하고, 과외 학부모와의 신뢰가 이 사업의 기반이기 때문입니다.

**교사 기여의 표현.** "선생님 덕분에 늘었다"를 문장으로 주장하지 않고, 수업에서 나온 표현을 아이가 혼자서 다시 쓴 기록으로 보여 줍니다. 정체된 주는 정체된 대로 보입니다. 좋은 숫자만 보여 주는 리포트는 한 번 의심받으면 전부 의심받습니다.

## 6. 확인된 외부 제약 (2026-11 기준, 착수 시 재확인)

| 항목 | 내용 | 설계 반영 |
|---|---|---|
| Workers 무료 | 일 10만 요청, 호출당 연산 10ms | 서버 로직은 가볍게, 무거운 계산은 기기에서 |
| Durable Objects 무료 | SQLite 방식만, 일 10만 요청, 일 13,000 GB-s, 저장 합계 5GB | 멀티 룸 가동 합계 하루 약 28시간. 싱글은 룸을 쓰지 않음 |
| D1 무료 | 일 500만 행 읽기, 10만 행 쓰기, 5GB | 계정·지표·리포트 |
| R2 무료 | 10GB, 전송료 없음 | 음성 클립, 스냅샷 |
| Workers AI 무료 | 일 10,000 뉴런, 초과 시 과금 없이 실패 | 수업 1회 약 2,160 뉴런(`가정`). 초과 시 뱅크 전용 |
| Realtime SFU·TURN | 월 1,000GB 무료 | 수업 창문의 실시간 음성 |
| 크론 | 무료 플랜은 계정당 5개 | 3개만 사용 |
| AWS 크레딧 | 무료 플랜 계정은 6개월 또는 크레딧 소진 시 종료 | 상시 서비스에 쓰지 않음. 일회성 배치에만 |
| Gemini API | 약관상 18세 미만이 쓸 수 있는 서비스에 사용 불가, 무료 등급 입력은 제품 개선에 쓰임 | 런타임에 쓰지 않음 |
| Claude 구독 | 구독 로그인은 자사 도구 전용, 외부 도구 연결 불가 | Claude 작업은 Claude Code에서 |

Cloudflare 수치는 공식 요금 문서에서, AWS는 공식 안내 문서에서 확인했습니다. Gemini와 Claude 항목, 크론 개수는 2차 자료로 확인했으므로 원문을 직접 읽어 보시기 바랍니다.

## 8. 가정

1. 수업은 대면과 원격 모두 가능하게 설계했습니다. 대면이면 교사 노트북과 학생 기기 2대를 씁니다.
2. 학생 기기는 최근 5년 내 노트북이나 태블릿으로 가정했습니다.
3. 초기 결제는 계좌 이체 후 좌석 수동 발급입니다.
4. 환율은 1달러 1,400원으로 계산했습니다.
5. 일정은 1인 + 코딩 에이전트 기준 추정이며, 첫 수업 가능 시점은 약 3개월 뒤(M3)로 잡았습니다.

## 9. 결정이 필요한 것

1. **수업 형태**: 대면과 원격 중 어느 쪽이 주인가요. 대면이 주라면 방 마이크 1개 구성을 먼저 만듭니다.
2. **학생 기기**: 노트북, 태블릿, 휴대폰 중 무엇인가요. 조작과 성능 예산의 우선순위가 달라집니다.
3. **참관 표시**: 기본값은 "교사에게 항상 표시, 학생에게 수업 시작 시 한 번 안내"입니다.
4. **가격**: 요금은 가설입니다. 과외비에 좌석을 포함할지 따로 받을지 정해 주세요.
5. **두 번째 언어**: 언어마다 원어민 검수가 필요합니다.
6. **제품 이름**: "LCW (Language Conversation World)"와 내부 가칭 "네더"는 출시 전 상표 검색 후 확정합니다.
